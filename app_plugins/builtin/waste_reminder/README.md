# 垃圾分类每日提醒

入口：主界面“今晚垃圾投放”面板，或插件 → 垃圾分类每日提醒。设置：程序设置 → 垃圾分类提醒。

主界面提前显示今晚 22:00 后应投放的垃圾（查询下一天收运，跨午夜后仍表示新的“今晚”）；显示未启用专项、无收运、未知数据及完成状态，不能把缺数据当无需投放。遵循主程序的可排序、可着色插件面板机制，不修改主界面业务逻辑。

分类可点击或右键查看详细中文说明；查询窗口底部分类和本周表格也支持右键。包含七类垃圾的 100 多个可投/不可投例子、常见误区、原始 PDF。物品说明与程序分离在 `data/category_details.json`；标注核实日期和年份，不将旧说明冒充新年新规。

程序设置中可选择本地 MP3/WAV/FLAC 等歌曲和音量。歌曲循环直到确认、推迟、提醒窗口过期或关闭插件；不存在/解码失败时显示提示、写日志并改用每 4 秒循环警告音。只在 Qt 主线程操作播放器，不启动额外模型。

默认：Valle Lomellina (PV)、Europe/Rome、前晚 22:00、有收运才提醒、中文＋意大利语、警告音、15 分钟推迟。Pannolini 默认不提醒，先向收运方确认服务适用性。弹窗阻止本软件内操作；等待 30 秒并勾选“已投放”后才能完成，不锁住操作系统，也不能判断用户实际上是否投放。

## 年度日历与官网解析

- 首次使用复制自带的 `data/schedule_2026.json` 和官方 PDF/JPG 到程序根目录下 `config/waste_reminder/`，不会覆盖已经存在的用户文件。
- `dates` 为逐日明细，`[]` 是不收运；缺日期、缺年度是**未知**，不会按星期规则补全。
- 每日后台检查官网；也可点击“检查并解析官方新日历”。自动发现当年和下一年的 PDF，解析全部 365/366 个单元格，校验年份、Comune、网格、星期与月份顺序、颜色、类别计数，再原子替换年度 JSON。
- 2026 首次内置数据另外与 Comune 的官方 JPG **全部 365 日交叉核对**，无差异；开发工具保留像素解析报告。
- 解析器是 Valle Lomellina / TeknoService 当前格式的适配器，不保证未来任意版式都可解析。官方格式变化时明确报错、保留下载的原件、保留旧日历；绝不猜测。可在 UI 打开原件和 JSON。
- 当官网发布 `schedule_2027` 对应的相同格式 PDF 时，程序自动解析并生成 `schedule_2027.json`，不是用 2026 的星期规律外推。没有发布前提醒缺数据。
- 保存原始 PDF、网页快照、SHA-256、发布日期/检查时间。同一 PDF 哈希不重复存储；旧 JSON 只在日期确有变化时备份。
- 其他 Comune 可更换日历目录、Comune、时区和文件名规则；自动解析当前只适配上述官网，不能声称支持所有 Comune。

## 联网注意事项与提醒可靠性

- 每日后台检查 TeknoService 的官方公告，只接受精确绑定 Valle Lomellina 的公告；其他 Comune 的规则不混入。
- 新消息在“官方最新消息”页展示，含日期、警示标识、原文、官网链接与下载原件；新公告触发桌面提醒。显示**上次成功检查时间**，断网不会冒充最新。
- 公告标题及正文后台自动翻译为中文，译文在前、意大利语原文在后；显示翻译服务和检查时间。优先 Google Translate 网页接口（并非有 SLA 的 Google Cloud API），不可用时使用 MyMemory 免费接口。免费服务可能限流、额度用完或改变接口；两者失败时明确显示未完成并保留原文，可点“翻译现有公告 / 重试失败翻译”。只发送公开公告，不上传配置、私有文件或歌曲；可在设置关闭自动翻译。
- 译文按清理后的文本 SHA-256 缓存，分段成功立即保存；失败重试不重复翻译已成功片段。原文改变则重新翻译。`translations.json` 最多保留 500 段；公告记录同时保存完成译文。已缓存公告无需重复下载日历便可补翻译；离线可读之前译文。
- 机器译文只帮助理解，不自动改写年度日期和经过核对的分类规则。现有中文小贴士是已核对资料的摘要，每晚轮换显示；新年/新规请同时阅读对应原件。官方 PDF 的字母跟踪间距先做可读性清理，原件始终保留。
- 已核实 2026-07-01 起干垃圾需扎好的半透明袋并放入指定桶，黑袋或桶外垃圾不收。这份新通知优先于旧日历图例。当地罚款金额没有核实，不编造罚款数字。
- 程序必须保持运行。默认不设置 Windows 开机任务、不锁屏、不强制阻止用户退出系统；关机时无法提醒。睡眠/重启后在 06:00 前补提醒，超过窗口不再要求超时投放。
- 确认、推迟时间在 `state.json` 持久化。推迟不算完成；修改后的收运类别重新提醒。时区使用 Qt 的 Europe/Rome 数据库，处理夏令时。
- 所有界面操作、弹窗、提示音在 Qt 主线程；联网和 PDF 解析在 QThread。关闭程序时请求停止后台检查，不强制杀线程、不硬等待。

年度 JSON 示例结构：

```json
{"schema_version": 1, "commune": "Valle Lomellina (PV)", "year": 2027,
 "timezone": "Europe/Rome", "exposure": {"from": "22:00", "until": "06:00"},
 "types": {"carta": {"it": "Carta e Cartone", "zh": "纸和纸板", "emoji": "📦"}},
 "dates": {"2027-01-01": [], "2027-01-02": ["carta"]}}
```

此例只是结构示例，不是 2027 的真实收运日期。

运行依赖新增轻量纯 Python 库 `pypdf`；不需要新 AI 模型。开发用 PDF 可视化和双来源校验工具不属于运行依赖。

## 主程序配置热更新

主程序每秒检查 `config.json` 的文件状态，稳定后读取外部变更；在模态窗口打开时暂缓应用。可在“程序设置 → 外观”关闭自动检测，“工具 → 重新读取配置文件”可手动检查。

安全热更新覆盖主题、音频配置、字幕参数、垃圾提醒；音频/日历后台任务运行时等待完成再应用。不在外部文件变更时重载 AI 模型、重新注册全部快捷键或重启后台服务，其他配置保留在磁盘并提示重启。

保存使用字段级合并：软件内未修改的旧值不会覆盖外部新值；不同字段的并行修改自动合并，同一字段同时修改时不覆盖并提示冲突。设置窗口也采用这个保护。无效/半写入 JSON 不应用，日志记录错误，不输出配置值或密钥。
