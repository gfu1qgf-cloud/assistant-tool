# 文字环绕／避让控件（1.38）

1. 在画布或图层列表选择标题、正文或普通文本框。
2. 控件属性中，位置／尺寸下面展开“文字环绕／避让控件”，勾选标题右侧的开关。
3. 勾选要避让的图片、视频、GIF或其他有位置框的文字控件，可同时选多个；设置间距和环绕方式。

默认关闭。支持两侧环绕、只走较宽一侧、只走左侧、只走右侧；间距按1080宽画布的像素缩放。
移动、缩放所选控件后重新排版；隐藏或不透明度为0的控件暂不占位。
勾选的控件按矩形外框避让，包括透明图片的外框；不会自动识别人物轮廓。图片／视频动画按静态外框计算，不逐帧改变段落。

也可点“绘制／编辑多边形…”打开当前设计画面，沿人物／物体逐点画轮廓；点击起点或按Enter闭合。
可画多个凸或凹多边形。点击区域选择，拖顶点改形状，双击边线加点，Delete删除选中顶点，拖内部整体移动；右侧勾选各区域是否启用。
“新增区域”继续画；“删除区域”移除当前区域；Backspace撤回未闭合的点，Esc取消本次绘制／拖动；Ctrl+Z、Ctrl+Shift+Z／Ctrl+Y撤销／重做。
“保存并重排”一次性应用到当前文字控件，仍可用主窗口Ctrl+Z整体撤销；“取消”不改项目。画布的轮廓、填色、顶点不会导出。
最多16个区域，每个3–128个顶点，边线不允许交叉。保存后按真实轮廓及统一间距排版，凹口可继续利用，不退化为外接矩形。
手绘区域固定在画布上，按百分比随输出分辨率缩放，不随图片移动或追踪视频。若用多边形替代图片矩形，请取消上方该图片的勾选，否则两种避让区域会合并。

文字仍在自己的文本框内排版，字号在最小／最大范围内自动选择。最小字号放不下时，设计预览显示提示并阻止正式导出，不截掉文案。
居中／底部对齐会在实际位置重新排版；复杂避让区域下优先保证文字完整和不重叠。
文字底色、描边和阴影同样不覆盖避让区域。设计预览、播放预览和正式导出共用排版，字幕／视频造成的原生图层拆分不会丢失避让对象。

参数随项目保存，支持Ctrl+Z撤销、Ctrl+Shift+Z重做。删除目标后保留其编号，撤销删除即可恢复关联；也可在清单里取消该项。
这项功能用于普通横排标题、正文和文本框；滚动文字、竖排和逐词字幕暂不支持。要切换为竖排或滚动，先关闭文字环绕。
节点效果暂不支持跨控件避让。参与环绕的文字或避让对象转换为节点时会明确提示，保留原控件；需要转换时先关闭相关文字的环绕。

排版只读取控件几何信息，不扫描素材目录或生成中间视频，不推进资源池位置。
实现使用Qt原生字形处理与逐行宽度／位置：[QTextLayout](https://doc.qt.io/qt-6/qtextlayout.html)、[QTextLine](https://doc.qt.io/qt-6/qtextline.html)。多边形间距使用Qt路径描边，按一整行的高度计算遮挡投影，不只检测文字基线。
