# 素材抠像工作台（1.21）

文案视频顶部 **抠像 → 素材抠像工作台**。也可以选择视觉图层后使用“抠当前图层／正在试看的素材”，或在图片、视频、自建视觉池里右键“单独抠像并保存”。

1. 添加图片／视频，选择一个素材。
2. 图片默认“通用主体”；人物视频默认“人物 · 视频时间记忆”。点击“生成AI遮罩”。
3. 用黑白遮罩、原图、叠加遮罩或透明棋盘检查；滚轮缩放、中键平移。
4. 调整精修参数，预览自动更新。预览下方直接选择“保留区域＋／去除区域－”，按住鼠标左键涂抹，松开算一笔。
   参数、涂抹、清空和重置共用撤销／重做：Ctrl+Z、Ctrl+Y或Ctrl+Shift+Z。每个素材分别记录会话历史；撤销不会回滚已保存文件。
5. 点击“保存结果并用于此素材”。图片保存透明PNG，视频逐帧生成无音轨透明MOV。
6. 资源池轮换到该素材时自动使用它自己的结果。没有保存结果的素材沿用原图及图层抠像配置。

保存的是完整素材结果和参数，不是一个套用到全池的统一配置。打开“查看已保存的素材抠像”后直接调整参数；缺少基础遮罩时在后台自动重建，之后精修复用该遮罩。切换回已有草稿时自动更新预览。不同素材分别保留未保存参数和最近8个素材的撤销历史，每份最多60步／2MiB序列化快照。只有点击保存才更新正式关联。

“原始素材”用于对比，始终显示原图；检查参数效果请选择“合成／透明棋盘”或“黑白遮罩”。视频仍只预览首帧。图层属性中的颜色抠像与本工作台是两处界面；画笔属于本工作台。

可“停用此素材的已存结果”或“启用已存结果”。视觉图层的“优先使用此素材已保存的抠像结果”允许单独改用原素材。使用已存结果时不重复叠加图层颜色抠像；位置、尺寸、混合、出入场及循环设置继续生效。结果以原素材路径和内容识别，也能匹配经图片池导入后转为PNG的相同解码像素副本。

## 精修参数

| 参数 | 作用 |
| --- | --- |
| 黑色／白色截断 | 将遮罩的暗端压为透明、亮端提为不透明，白端必须大于黑端 |
| 清理黑色／白色区域 | 逐步压低半透明背景或提升主体覆盖率 |
| 遮罩降噪 | 中值过滤小噪点，0关闭 |
| 收缩／扩张 | 以处理素材像素计算，负值收边，正值扩边 |
| 边缘引导平滑 | 利用原图灰度边缘引导遮罩平滑 |
| 羽化半径、内外比例 | 柔化边界；负比例偏向内侧，正比例偏向外侧 |
| 反转、不透明度 | 反转主体选择；最终整体透明度独立控制 |
| 去碎块、碎块尺度 | 重建保留有核心的连通区域，清除悬空细碎残片；可用保留画笔保护小装饰 |
| 边缘去色 | 对遮罩边缘压低绿／蓝偏色，可调强度、范围和亮度补偿，保持Alpha不变 |

原素材原有透明度始终相乘，画笔和扩张不能复活源Alpha为0的像素。尺寸单位指当前解码素材像素；静态图片解码最大边8192，最多4000万像素，图片池导入仍沿用4096边界。

## 模型和实际设备

- 通用主体：IS-Net general-use，固定1024分析尺寸，适合图片中的人物和物体。
- 人物：RVM MobileNetV3 FP32，保留相邻视频帧的循环状态；快速／精细的最大内部分析边分别为320／512。适合人物，非人物可改用通用主体模型。
- ONNX Runtime仅在处理时加载。自动优先使用实际可用的CUDA执行器，否则CPU。显式选择CUDA而环境不支持时会明确报错，不冒充显卡推理。
- 当前电脑已实测的环境为CPU执行器。没有更换现有Torch或CUDA环境。首次使用下载约170MiB和14MiB两个模型，核验固定SHA-256；不上传素材，不执行远程代码。

这里借鉴专业遮罩精修的调节方式，使用独立开源模型与算法。没有复制达芬奇的专有魔术遮罩。画笔是手工像素区域修正；视频工作台预览首帧，画笔固定在素材坐标，**不会自动跟踪运动**。生成整段透明视频后，可在文案视频的播放预览检查动作。

## 保存及复用

私有目录位于程序当前数据根目录的 `BatchTextVideo/Matting/`：模型在 `models/`，结果在 `assets/`，关联与参数在 `catalogue.json`。这些运行数据不进入Git。

每次保存生成新版本，旧结果保持不变，以免覆盖正在导出的文件。目录记录原子更新；失败／提交前取消会清理本次暂存并保留先前结果。原子提交完成后的取消仍报告成功保存。重做、另存结果均不会覆盖原素材。

已绑定的原素材或透明文件被修改／删除时会提示重新抠像或改用原素材，避免悄悄套用旧遮罩。图片、MOV、设计首帧、播放预览、正式导出及节点转换复用同一结果，不在每次导出时重新调用AI。轮换计划在替换渲染路径前生成，不更改条目ID和成功推进规则。节点提交时冻结已存结果、捕获原素材与结果文件，两者均参加资源检查。

“另存透明结果”可以导出PNG／MOV副本。MOV使用QTRLE保留Alpha，通常比原MP4大；它是可重复使用的素材文件。普通成品MP4仍为背景合成结果。视频保存不保留音轨，符合叠加视觉素材原有的静音用途。
