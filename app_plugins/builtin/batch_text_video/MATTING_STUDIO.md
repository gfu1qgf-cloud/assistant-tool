# 素材抠像工作台（1.43）

文案视频顶部“抠像 → 素材抠像工作台”，或选择图片／视频图层后点击“AI抠像工作台”。

1. 添加图片或视频，选择素材。图片默认通用主体模型，人物视频默认有时间记忆的人物模型。
2. 视频画布下方有播放／暂停、上一帧、下一帧和进度条；拖动后松开定位，方向键可微调。播放到末尾后可从头重播。
3. 视图可以切换原片、合成／透明棋盘、黑白遮罩、叠加遮罩。原片播放只解码、不运行AI；其他视频视图按当前参数逐帧抠像。预览无声，AI速度取决于设备，状态会显示实际设备和帧率，可能低于原速。
4. 修改参数会暂停视频并更新当前帧；缺少原始AI遮罩时在后台重建，已有遮罩时复用。换模型、质量或设备后仍在所选帧重建。跳转或重新开始播放会重置人物模型的时间记忆，连续播放时复用该次的时间记忆。
5. 暂停后可选择“保留区域＋／去除区域－”涂抹；滚轮缩放，中键平移。画笔固定在素材坐标，作用于整个素材，不自动跟踪运动，也不是仅对当前帧的关键帧修改。
6. 参数、涂抹、清空和重置共用撤销／重做：Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z。定位和播放不会消耗参数历史。
7. 点“保存参数并用于此素材”后才会更新正式素材关联。即使在视频中间保存，保存的仍是整段素材的参数，不截短视频。

预览只保留当前帧及有背压控制的一帧交接，不缓存整段视频，不生成透明MOV。暂停、切换素材、隐藏或关闭工作台会停止自己的解码与预览线程；主程序退出也会等待这些本地线程。原片播放不需要先下载或运行AI模型。

## 控件属性与工作台谁生效

- 勾选“使用工作台已保存的抠像结果／参数”时，每个素材完整使用工作台已保存配置：补洞、收边、去碎块、透明度精修、画笔、去溢色都以工作台为准。下方会重复处理的抠像参数禁用，位置、尺寸、整体不透明度、叠加和动画仍可调整。
- 勾选后，未保存工作台配置的素材保持原素材，不使用灰掉的外部参数。
- 取消勾选后，恢复使用控件的统一颜色／AI抠像参数，不读取工作台已存参数。可以保留两套设置，切换时不删除它们。
- 同一个资源池的每个素材可以分别保存不同配置，例如有的补洞、有的不补洞。批次提交时冻结每个素材的已存配置，后续修改不会混入正在导出的批次。

保存参数不会生成整段透明MOV；旧的透明PNG／MOV结果仍可原样使用。需要独立透明文件时，用“另存透明结果”显式导出PNG／MOV，透明MOV通常较大，不作为预览缓存。停用／启用已存结果不会覆盖原素材。

工作台草稿、当前帧和播放位置属于本次会话；素材轮播及最终输出使用已保存配置。切换素材可保留各自草稿与最近8个素材的撤销历史，每份最多60步／2MiB。原片视图只用于对比，检查抠像请切换合成或遮罩视图。
