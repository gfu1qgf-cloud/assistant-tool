# 图片、GIF与视频的入场／退场

入口：选择视觉图层 → 属性 → **入场与退场** → 勾选启用。

入场、退场可分别选择：直接显示／消失、淡入／淡出、左／右／上／下滑动并淡化、由小放大／由大缩小并淡化。方向、用时相互独立，运动幅度可调。

- “开始”之前隐藏；“结束”是退场完成时刻，0表示视频末尾。
- 时段短于出入场用时总和时，会按比例缩短动画并留出完整显示阶段。
- 图片出入场与原“动画”中的呼吸、律动、浮动和缓慢缩放可以叠加。
- GIF／视频默认从出现时开始播放，可选择跟随全片时间；源素材及其音轨不被修改。
- 默认关闭，旧项目保持原表现。参数按图层保存，支持原有撤销／重做及转换为节点效果。

画面下方的“动画快览”可拖动检查开始、中间和结尾，无需编码整片。设计画面与快览使用素材首帧；GIF／视频完整动作请使用播放预览。

原节点入口“视频与画面 → 时间控制 → 显示时段”继续可用，原生控件复用它的缓动、透明度和渲染实现。若再显式连接显示时段节点，外层节点的时段优先，避免重复淡入／淡出。
