# 资源池试看（1.20）

图片／GIF／视频图层的“来源”绑定默认图片池或自建视觉资源池后，设计预览下方出现“资源池试看”。

- 上方选择要试看的图层；默认跟随当前选中的资源池图片图层。
- 下方可按文件名下拉选择，或用“上一张／下一张”循环切换。
- “按生成顺序”显示正式下一项；“恢复生成顺序”清除所有图层的临时试看选择。

设计视图、动画快览和播放预览均使用这次选择，抠像、去碎块、去色溢及动画参数保持同一套。
GIF／视频在设计视图中仍显示首帧，检查运动请用播放预览。

试看仅保存在当前窗口内存：不会写入项目、不改源文件、不修改实际轮换游标、不调用成功后推进逻辑。
多个视觉图层可各自选择不同素材；按条目稳定ID记忆，池内重新排序不会看错文件。
移除已选条目、改变来源池、切换项目或关闭重开后回到正常选择。
批量生成始终沿用正式轮换顺序。为避免把试看图误当作正式选材，试看期间点击“快速导出”会提示先恢复生成顺序；恢复后按钮、菜单及Ctrl+E仍按原规则工作。
资源池为空时禁用切换；文件丢失时沿用明确的预览错误提示，可继续切换其他素材。

范围：原生视觉图层（默认／自建图片、视频、混合视觉池）；节点内部的独立素材池仍通过节点编辑器预览。
