# 智能搜图

本地中文文字检索、以图找图，以及参考图片＋补充中文描述的组合检索。
原图不上传到网络；仅首次模型下载需要联网。没有新增 Python 依赖。

## 模型与索引

- Base：保留原模型 ID 和 `SmartImageSearch/index.sqlite3`。
- Large：使用 `index-large.sqlite3`。
- Large／336：使用 `index-large336.sqlite3`，图像输入分辨率更高。

模型可在搜图窗口或插件设置中选择，选择会保存到原配置文件的
`smart_image_search` 段。已有用户默认不变，避免升级后忽然失去可搜索的旧索引。
新模型第一次需要点击“增量更新索引”；停止会保留已完成批次，下次继续。
缩略图共用，模型特征不能混用。原图库只增加新图时只计算新增／变化的图片，
移动出去的文件不会要求全库重建。切回 Base 不会重新下载或重建旧特征。

三种模型均固定原模型仓库中的 SafeTensors 版本，不加载 pickle 权重或远程自定义代码。
Large 两个版本各约 1.63 GB。CPU 也能运行，但首次建库及分析参考图会慢于 Base；
日常检索只需编码搜索条件并对已有向量排序，不会重新分析全部原图。

## 组合检索

在“以图找图”中拖入参考图片，可选填“补充描述”，再调整“文字侧重”：

- 留空：仅按参考图片检索。
- 0%：只看参考图片。
- 100%：只看补充文字。
- 中间值：把同一模型归一化后的图片／文字向量加权，综合排序。

这是相关性偏好，不是严格筛选，也不是图片编辑；“不要红色”等否定描述不保证可靠。
分数只是模型相似度，不是准确率。未加入独立的 DINO 外观模型或用户偏好训练。
重复搜索条件在会话内缓存；参考图修改后缓存失效，模型切换时不混用缓存。

## 验证

`python -m unittest tests.test_smart_image_search tests.test_main_plugin_integration`
覆盖旧索引保留、独立模型索引、组合权重、后台任务期间延迟切换、选项保存、
增量更新、拖拽移动和缩略图比例。

`python -m tests.benchmark_smart_image --source-index C:/path/index.sqlite3 --output C:/path/report.json`
只读生产索引，使用独立测试索引，输出候选拼图及真实耗时。不改原图，
不会用文件名修正模型排名，也不凭相似度分数宣称精度提升。
