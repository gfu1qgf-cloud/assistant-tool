# 智能文案分段节点

在节点搜索中输入“智能文案分段”，或在“文字处理”分类中添加。需要启用“智能文案分段助手”插件。

将“任务文案”或“文本”节点接入“原始文案”，选择“优先完整句”或“减少段数”；默认优先完整句。可选择自动6/8/10秒或固定时长，并调整语速、停顿、预留和整篇提醒上限。参数随工作流保存，不依赖分段窗口中保存的默认参数。

主要输出“分段列表”是原生 Python `list[str]`，按原文顺序，每项只含一段正文。不是字符串形式的列表，也不是 JSON 文本，不加段号、建议秒数、任务标题或警告。原文里的引号、数字、序号和换行会保留。

例如输出值为 `['第一段正文。', '第二段正文。']`。可以直接连接“列表 · 取项”“列表 · 切片”“len() · 长度”或列表遍历节点；检查结果时连接“预览”。下游若需要 JSON，可显式添加 `json.dumps · 转 JSON 文本`。

独立输出还有段数、预计朗读秒数、整篇超时布尔值和时长提醒文本。默认整篇预计朗读超过180秒时，整篇超时输出真，时长提醒和运行进度给出提示；不弹窗等待确认，也不把提示混入正文列表。视频时长或各段预留不累计到整篇朗读时长。

节点复用原分段算法及短尾合并：优先完整句策略下，预计朗读不超过3秒的末段可并入前段，含预留最多超出所选时长3秒；单段超时在独立提醒中报告。节点不改写或翻译原文，不调用AI、不操作剪贴板、不保存文件、不修改任务表。
