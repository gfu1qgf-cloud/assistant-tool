# 智能搜索 2.0

入口：插件 → 智能搜索…。一个插件管理图片、音乐、视频三个分页；程序设置 → 插件设置 → 智能搜索。

原搜图和搜音乐的配置键、模型缓存、索引目录及数据格式不变，不用重新下载或重建。图片/音乐子模块保留为内部能力，不再分别安装到主程序。插件管理只有一个启停选项；原两项均禁用时保持禁用。

## 视频

1. 打开“视频”分页，点“视频库 / 索引设置…”，添加本地视频库。默认也包括库存/人物素材目录。
2. 点“建立 / 更新索引”。任务提交到主程序后台任务，隐藏搜索窗口仍继续，可在后台任务或搜索页停止。
3. 用中文描述、参考图片或两者组合搜索。双击从命中位置预览，右键查看其他命中时间、打开原文件/目录、复制路径。可多选拖入达芬奇（复制/引用，不移动原文件）。默认每批100个，可继续加载。

默认复用中文 CLIP Large/336 的固定 SafeTensors 权重，与搜图共用下载缓存；可选择其他模型，每种模型的索引独立。只按画面语义匹配，不识别对白、剧情、完整动作或音轨。分数仅用于排序，不是准确率。

用 FFmpeg 低分辨率换镜头检测补充代表帧，另保留开头/末尾和均匀全片覆盖。采样间隔、单视频帧数上限、镜头阈值均可改；小于采样间隔的短镜头和叠化仍可能遗漏，不承诺全帧检索。达到帧数上限后间隔自动增大，设置页说明。建库耗时随数量、长度和模型增长；搜索本身只查本地向量。

新索引：`SmartVideoSearch/index-{model}.sqlite3`、分模型缩略图目录，Git 忽略。只更新大小/修改时间/采样设置变化的文件；取消保留已提交的视频记录，单视频解码失败保留旧记录，原视频不改动。查询暂不显示已移走或已改变但未更新的文件。无视频/目录无法访问时明确报错，不清空旧库。

模型未缓存时会先询问下载；原素材不上传。统一加密尚未实施，此次不改变现有数据保护策略。

验证：`python -m unittest discover -s tests -p test_smart_search.py`；包含真实 FFmpeg 的开头/换镜头/尾部检索、增量缓存、取消保护、分页/拖拽、插件合并与退出生命周期测试。
