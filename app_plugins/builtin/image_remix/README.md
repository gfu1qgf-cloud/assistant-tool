# GPT 图片翻版

## 补全 Batch 缺失图片（0.4.1）

- `Batch · 部分完成 · 已收取 1/10` 表示该轮已结束，并非仍在排队生成余下图片。选中记录，点击 **补全缺失 9 张…**，确认新增费用后，只重新提交这 9 个明确失败项。
- 按钮右侧箭头提供 **补全全部 Batch**，确认框汇总本次批次数与图片数；已取消但仍有明确失败项的批次也会列入，请在确认前核对。
- 已成功图片不重做、不覆盖，沿用原始任务的提示词、模型、参考图快照和提交账号。补全是新一轮付费 Batch，仍需等待云端处理，不无限自动重试。
- 仍在生成、提交结果不明、结果收取异常、提示词尚未完成、即时模式的记录，不加入此批量补全。生成中继续等待；结果不明或收取异常先用 **检查并收取结果**。即时模式保留原有右键继续／重试入口。
- 执行前在运行锁内重新核对已确认的批次令牌和失败项列表；期间状态变化的记录跳过，避免重复点击或旧确认重发。原账号缺失等单批异常会单独提示，不影响其他可处理批次。
- 更新后正常重启软件生效；不热重载运行中的提交代码。无需修改现有任务数据库或重新生成已有提示词。
