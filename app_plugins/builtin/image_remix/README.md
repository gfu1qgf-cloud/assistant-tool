# GPT 图片翻版

## 审核失败自动合规修正（0.5.0）

- 新任务默认勾选“审核拦截时，AI合规改词后自动重试一次”，可关闭。提交确认会说明额外文字和生图费用。已有任务不被后台擅自改动；已有失败项点击“全部补全”并确认时，按此开关启用新流程。
- 仅对明确的 `moderation_blocked` 启动修正，将失败提示词、审核原因、可选参考图快照与安全可保留的风格要求交给文字模型。要求实质删除／调整不合规内容，保留安全核心主题，不使用暗语或同义词规避审核，不承诺审核一定通过。
- Batch模式的修正走文字Batch，完成后自动提交修正项的图片Batch；即时模式走即时文字／图片API。无需逐项点击，关闭面板不取消，正常重启后继续原阶段。成功图片不重做，原始创意方案不覆盖。
- 每张图片最多自动修正一次。空词、拒绝、格式错误、原样照抄、再次被拦的项目不再自动重复提交；显示“审核需核对”，保留具体错误供人工核对提示词／参考图。其他独立成功修正项仍可继续。
- 保存原词、新词、文字模型、响应标识、用量和逐轮错误；在记录右键“查看提示词与错误详情”中查看。成品旁的JSON也记录修正来源。所有记录仍使用已有宿主受保护存储，不另存密钥。
- 提交结果未确认时保留原请求并恢复／查询，不能当作审核失败重写重发。取消／停止会阻止后续图片提交，不保证已发送请求可撤回或退费。数据存储版本升为5，旧版图片翻版客户端拒绝打开，避免误处理新流程；请正常重启使用，不热重载。

## 一键全部补全 Batch 缺失图片（0.4.2）

- `Batch · 部分完成 · 已收取 1/10` 表示该轮已结束，并非仍在排队生成余下图片。直接点击面板 **全部补全（N批／M张）…**，确认一次新增费用后，程序自动处理所有符合条件的Batch，不需要选择任何记录或逐批操作。
- 确认框汇总全部批次数与缺失图片数；已取消但仍有明确失败项的批次也会列入，请在确认前核对。只想处理单批时，右键该记录选择 **补全当前Batch缺失图片…**。
- 已成功图片不重做、不覆盖，沿用模型、参考图快照和提交账号；普通失败沿用原词，启用合规修正的审核失败项使用保存的新词。补全是新一轮付费 Batch，仍需等待云端处理，不无限自动重试。
- 仍在生成、提交结果不明、结果收取异常、提示词尚未完成、即时模式的记录，不加入此批量补全。生成中继续等待；结果不明或收取异常先用 **检查并收取结果**。即时模式保留原有右键继续／重试入口。
- 执行前在运行锁内重新核对已确认的批次令牌和失败项列表；期间状态变化的记录跳过，避免重复点击或旧确认重发。原账号缺失等单批异常会单独提示，不影响其他可处理批次。
- 更新后正常重启软件生效；不热重载运行中的提交代码。无需修改现有任务数据库或重新生成已有提示词。
