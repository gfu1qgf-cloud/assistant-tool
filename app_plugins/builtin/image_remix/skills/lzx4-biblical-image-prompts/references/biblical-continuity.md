# 故事时间线、钉痕与合理伤口

## 首要原则

钉痕判断要同时满足 **事件发生时间** 和 **相应肢体在画面内可见**。不能机械地“所有耶稣有钉痕”，也不能把复活后张开给观众看的手写成完全无伤。用户特别关注缺钉痕及巨型钉子两种相反错误。

| 阶段 | 身体伤痕规则 | 典型题材 |
| --- | --- | --- |
| 受难之前 | **没有手脚钉痕**；身体干净 | 湖边讲道、牧羊、受洗、变容、荣进耶路撒冷、客西马尼祷告、扛十字架尚未钉上 |
| 正被钉十字架 | 手/脚与木梁的受难固定关系准确；钉伤自然克制；荆棘冠及少量鞭伤 | 十字架近景、全景、三座十字架 |
| 被刺肋旁之后至安葬前 | 如**右肋**露出并朝镜头，应可见清晰小型长矛刺伤；手脚如露出有合理钉痕 | 从十字架卸下、玛利亚扶持遗体 |
| 完成安葬，裹殓布 | 从颈部以下完全盖住时，只露脸；**不为了伤痕掀布、割洞** | 岩石墓室石台、送葬担架 |
| 复活/升天/荣耀 | 手掌/足部**明确朝镜头展示时**，自然呈现愈合后的细小受难印记；手背看不到掌心不强求 | 墓口伸手、天堂迎接、升天、救赎特写 |

## 尺寸与位置

- 用“已经愈合的细小钉痕”“自然克制的受难印记”，避免“巨大铁钉、巨洞、深黑穿孔、暴露骨头”等诱发错误的措辞。
- 十字架上双臂与横木真实连接，手腕/手掌受伤位置依构图自然；脚部以合理固定和正常比例为先。**脚托仅在原图/用户要求对应时写出**，若有脚托应短小稳固并贴合竖梁，不是巨大台阶。不要执着夸大物理钉子。
- 耶稣被卸下后，可见脚/手伤，但**不能还留着钉子**。
- 右肋枪刺发生在十字架受难阶段后期；背十字架、客西马尼园、尚未受枪刺的场景不出现肋伤。肋伤可见时让侧胸面对镜头，不被别人手臂遮住；不要污秽/血腥化。

## 耶稣安葬与复活的空间关系

- 第一世纪犹太地区的凿岩石灰岩墓：低矮外门、短前室/通道、较深的主墓室、靠墙开凿石质安葬台。圆形封墓石位于**入口外侧**，不是内室石台旁边。
- **完成入殓**：耶稣已经躺在主墓室内的石台上，头部露出，颈部以下完整盖白色殓布；不裹头、不做木乃伊。身体与床台受力自然，不能躺在门槛上。
- **送入墓穴**：镜头放在队伍后方/侧后方，担架与行走方向指向墓穴；抬送者面向洞内，担架前端进入洞口，后端仍在外，耶稣头朝内部、脚朝镜头近处。严禁拍得像从洞里抬出来。
- **复活出墓**：若原图是背影，必须保留背影；摄影机在墓内靠后，耶稣穿全白袍沿通道走向外面金白晨光；墓外植物与山野可见，封墓石移至外侧。
- 墓穴可以神圣明亮：奶金色石灰岩、反射暖光、白色布料，结构清楚；不要恐怖漆黑，但也不无故改成现代白色宫殿。

## 升天

- 很低机位陡仰拍，耶稣在中上部仍需**够大且完整**，双臂展开，身体真正往上升；门徒仅占下缘小部分且望向上方。正常白袍、金白光、层云和蓝天。既要真实的上下距离，也要明显的升腾感。
