# 可直接复制的图片提示词样式示例

本文件用来校准表达精度，不是要求所有场景统一加入这些服装、光线或钉痕。下面每条独立完整，示例中的人物阶段须和实际参考对应。

## 示例一｜近景悲悯耶稣伸手（复活后）

**图片提示词：**

9:16竖版，超现实写实的电影级神圣肖像。摄影机位于耶稣正前方稍偏左侧，近距离中近景，耶稣约30岁，脸部占画面上半部，上身微微前倾，一只手从左下方朝镜头伸出，掌心向上、手指自然弯曲，形成清楚真实的近大远小透视，掌心有细小、已经愈合的受难钉痕。耶稣棕色中分及肩长发自然柔顺，发尾微弯、不像烫发，整洁胡须，眉头轻皱，眼眶微湿，目光深沉慈爱且直接注视观众。衣着为明亮洁净的圆领象牙白长袖长袍，单幅颜色饱满的正红色布料从一侧肩膀斜向身体外侧自然垂落，胸前白色衣料清楚。身后是暖金色日落照亮的山丘与层云，右后方斜射阳光在发丝形成细腻金边，脸部有充足柔光，红白衣色清澈纯正。画面温暖庄严，不包含字幕、水印、底部花朵或平台 UI。

## 示例三｜扛十字架，耶稣尚未被钉（受难前期）

**图片提示词：**

9:16竖版，超现实写实的耶路撒冷古城受难行进画面。镜头从人群右前方略低位置拍摄中全身，耶稣身穿洁净的米白色长袖古代长袍，棕色中分及肩长发微乱但不夸张卷曲，头戴荆棘冠，面容疲惫坚忍。肩膀承受一座**由一根直竖梁与一根直横梁垂直连接**的结实传统木十字架，粗厚木材贴靠肩背，耶稣两只手分工稳住木梁，身体随重量自然前倾，脚步向画面右前方迈出。身后有罗马士兵与不同年龄的成年围观群众，士兵铠甲、城墙、石路比例真实。下午明亮日光从古城墙间照入，画面清楚、庄严、沉重。此时尚未被钉，**手足没有钉痕**。其他男性面孔与耶稣明显不同，无字幕和水印。

## 示例四｜耶稣从墓中走出，后视镜头

**图片提示词：**

9:16竖版，超现实写实，晨光神圣而明亮。摄影机在第一世纪犹太岩石墓穴深处，从耶稣**正后方**拍摄中全身背影。复活后的耶稣穿洁净纯白圆领长袖长袍，棕色中分及肩自然柔顺长发露出后脑与肩背，正沿短通道朝洞口外明亮的金白朝阳缓步走去；身体背对镜头，完整手臂和脚步清楚，足部若露出仅有细小自然的愈合旧伤痕。洞口厚石灰岩与墓室内部有真实过渡，圆形封墓石滚到入口外侧，洞外见浅金色碎石、银绿橄榄叶、白色小花、起伏山野。光束从外向内照亮岩壁和白袍轮廓，空间清晰、温暖，不改成正脸或正对镜头伸手。无文字与后期装饰。
