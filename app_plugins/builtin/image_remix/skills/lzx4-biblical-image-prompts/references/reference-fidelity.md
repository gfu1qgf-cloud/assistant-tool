# 参考图阅读、翻版与审美决策

## 先识别画面，不先写漂亮形容词

观察时确认以下 12 项，再决定措辞：

1. 参考是单图、视频分镜拼图、上下合成图，还是 UI 截图？
2. 画面有效序号、重复镜头、黑屏和用户指定要哪个？
3. 主体是活人、雕像、图案、玩具、后期贴图，还是背景？
4. 主体占画面多少（特写/中景/全身/远景）？正中还是侧边？
5. 摄影机在主体的前/侧/后方？高位俯视、平视还是低位仰拍？
6. 人物的身体、面部、手、脚分别向哪里？看镜头或看旁人？
7. 人物是在站、坐、跪、倚、躺、走、上升或被抬？重力由谁承担？
8. 主体周围有几人，各人在前/后/高/低、远/近什么位置？
9. 衣服是全白、单幅斜向红披布、完整有袖红外袍、受难遮羞布还是其他？
10. 背景有哪些**实际环境物件**（岩壁、洞口、木船、教堂、阶梯、门、湖、树）？
11. 太阳/月亮/圣光从哪边来？主体哪些区域被照亮？
12. 哪些是后期文字、翻译、社交按钮、logo、右下角金色圣体、底部玫瑰或装饰？默认去除。

## 翻版 vs 创新

- **翻版** = 保持主视觉位置、情绪、镜位和物件关系，改写为可控的清晰场景。不要因为觉得更电影感便把低角度改高角度、坐姿改站姿、手势改对镜头、马槽改宫殿、人物年龄换掉。
- **场景创新** = 保持人物类型与故事逻辑，改变建筑、自然景观、路径、天气、光影与镜头关系等实质元素。不要重复“山坡＋白花＋金色日落”十遍；每张需有可辨识的独有空间设计。
- **用户纠错** = 保留正确部分、精准替换错误项。例：“第一个衣服发黑”应修改色彩和补光，不应同时改角度、表情和背景。

## 比对示例

- 参考为山脊侧面耶稣，远景连绵山谷和侧后方夕阳：写清镜头在左侧平视、耶稣面朝画面右、脚下金草、太阳在右后、衣服正面有补光。若只写“群山落日光辉”会跑角度。
- 参考为高机位俯拍湖边耶稣讲道，众人围坐、远处两艘木船：耶稣必须是群像中的适中小主体，不能变成单人大特写。
- 参考为“人群由墓外抬入墓内”：相机放在**队伍后方**，所有人朝向洞口，担架头端已入洞，脚端仍在外。这比“正在往里抬”一个抽象词更稳定。
- 参考为天国阶梯上的耶稣：注意阶梯与宫殿大门连通，耶稣到底在台阶顶端、前端还是中段，衣色红白是否参考一致。
- 参考为巨大耶稣面容＋下面祈祷的人群：必须明确上下层的约 2/3、1/3 占比，云光自然融合；不要删掉下方众人，也不要让背景人群复制耶稣。

## 光线基准

- 优先：真实的暖金斜射阳光，**位置明确**，如右后方侧逆光形成柔和金边，正面有充足柔光，不使脸部或白袍变暗。天空清澈、层云真实、对比和细节受控。
- 受欢迎的强项：壮丽雪山与湖泊、翠绿牧场、花园池水、古老墓穴透入奶金色晨光、天堂可进入的金白圣殿、银河桥与云海；每张实际使用哪些依参考。
- 避免：满图偏黄/偏蓝/紫雾、阴森灰暗、脏旧的白袍、纯塑料 CG、过曝失掉脸部、无缘无故加满画面的百合/鸽子/天使/宫殿。
- 夜景可以深蓝与月光，但需看清人物姿势、手与石头的接触，以及环境层次。

## 负面词的使用限度

尽量用**肯定式可视化描写**而非“不要”的长名单：例如“洁净明亮的圆领白袍、单幅红布从左肩斜落、布面宽大柔软”比“不要围巾，不要外袍，不要披风，不要……”更稳定。可以在末尾只保留最关键的两类排除：**不符合故事/解剖的错误**和**后期 UI 字幕装饰**。用户明确删去元素时直接从肯定描写里移除，不必每段反复提其名字。
