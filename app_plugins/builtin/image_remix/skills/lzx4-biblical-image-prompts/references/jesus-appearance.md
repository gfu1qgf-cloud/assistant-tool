# 耶稣形象与衣服｜稳定基准

## A. 固定外貌（成年人）

- 约30–33岁的成熟俊朗成年男子，正常身材与人体比例。要有真实人的表情与肤质，不像玩偶或健美选手。
- 棕色中分及肩长发，发丝自然柔顺、发尾仅轻微弯曲，稍有自然起伏；避免密集卷、烫发感和异常夸张蓬松。深棕色自然胡须，整洁、长度适中。
- 面部自然成熟，眼神深邃温和。不同镜头保持同一个耶稣的年龄、五官和头发连续性，不要在变化镜位时换脸。
- 不自动添加荆棘冠、王冠、圣心、光环、手伤或权杖；只在参考/主题明确对应时出现。荣耀君王若参考有王冠，优先简洁款；明确要求不带权杖、十字架装饰时不得出现。

## B. 衣着决策：按具体参考，不强制一种套装

| 参考或场景 | 正确写法 | 高频失败 |
| --- | --- | --- |
| 普通圣经、复活、山野白袍 | 洁净明亮的白/象牙白**圆领长袖长袍**，垂感真实，领口正常；束带按参考需要 | 暗灰、脏黄、过度破旧、奇异大围脖、头巾感、无端复杂叠穿 |
| 白袍+红色**斜向披布** | 一整幅颜色饱满明亮的红布，搭在一侧肩，从肩向胸侧/身体外侧斜向垂落，胸前白色圆领清楚 | 披布变完整外套、宽围脖、披肩横盖双肩、脏黑酒红色 |
| 白袍+红色**完整外袍** | 红色外衣有衣身与袖子，结构完整，外衣边缘自然垂落，白袍在前襟可见 | 随意挂在肩上的红围巾、无袖一块布、两个不同外衣混合 |
| 全白复活/升天 | 洁净完整的白色圆领长袖长袍，按镜头可以有正常白色外层垂布 | 擅自加红、皇冠、金边、头巾、过度金色饰品 |
| 刻画十字架受难 | 上身赤裸；下身使用固定受难像遮羞布；荆棘冠及轻微伤痕 | 在背十字架之前就加钉痕；无端血腥与肮脏 |
| 特定荣耀君王绿幕 | 按参考保留适度简洁王冠与衣着；一只手伸向镜头；背景纯绿 | 权杖/十字架装饰被用户删去后又出现，满身宝石与过度奢华 |

受难遮羞布固定短语：**“主耶稣下身穿米白色传统受难像遮羞布，前方自然交叠褶皱，一圈式包裹。”**

避免将衣服写得过于繁琐。先决定红色布料究竟是“斜披一幅布”还是“完整外袍”，再用一句清楚的肯定句描述；只强调极少数必要排除项。相同色彩可以依参考选择正红、传统深红、明亮酒红，始终不要压成黑棕。

## C. 表情与动作依剧情决定

- 教导/祝福/好牧人：自然温柔或真诚微笑；动作松弛而亲切。
- 灾难中守护/救援：专注、忧虑、坚定、怜悯；危险发生时不可一脸开心。
- 受难/临终：沉重、悲伤、疲惫而坚忍；伤痕克制；不要摄影棚摆拍微笑。
- 客西马尼园：痛苦、忧虑、真实汗珠，侧面/侧后方低头祷告；不得为追求感染力擅自加眼泪。
- 复活/天堂：平和、喜悦、安慰；可微笑。若主题明确悲悯哭泣，则眼眶湿润和细小泪痕自然，不做夸张表演。
- 伸手特写：眼神与手势情绪一致，掌心面向镜头，五指解剖正确、透视有层次；不能仅有伸手没有靠近观众的空间感。

## D. 多人镜头

旁人不能复制耶稣：门徒、约瑟、士兵、群众须在脸型、年龄、发型、胡须和衣服上明显不同。玛利亚的年龄依故事阶段：圣婴诞生时年轻，耶稣受难时是成熟中年女性。约瑟可设成熟成年男性，不默认老得不合理。不要默认添加儿童；儿童、幼年天使仅在具体参考/主题需要时添加。
