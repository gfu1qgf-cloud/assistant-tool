# 临时 TOTP 验证码

入口：插件或工具菜单 → **临时TOTP验证码**。

1. 粘贴Base32密钥或 `otpauth://totp/` 链接，点击生成；也可点“粘贴并生成”。
2. 点击大号验证码复制。显示有效期倒计时，临界时重新计算后再复制。
3. 高级设置可选SHA-1/SHA-256/SHA-512、6/7/8位、周期；链接会自动读取参数，不支持的算法／HOTP／特殊编码会明确提示，不静默替换。

默认SHA-1、6位、30秒。只支持数字TOTP，不是KeePassXC数据库、密码管理或Steam口令的完整替代品。实现独立遵循[RFC 6238](https://www.rfc-editor.org/rfc/rfc6238)，未复用KeePassXC源码或素材；链接采用[Key URI约定](https://github.com/google/google-authenticator/wiki/Key-Uri-Format)。

## 临时性与隐私

- 无存储文件、账号列表、历史、配置保存、日志、后台任务载荷或网络请求。载入成功后清空输入框及撤销历史；关闭／Esc／停用插件／退出程序会清除会话。直接销毁窗口也会清除密钥持有器。
- 密钥可变缓冲区做尽力覆盖，但Python、Qt和HMAC可能存在副本，**不宣称安全内存零残留**，也不控制系统交换文件或内存转储。
- 复制只包含数字验证码，带程序内部复制标记，并设置Windows“排除剪贴板历史／云同步”的格式标志。计划20秒或验证码到期后，仅在所有权标记及内容仍匹配时清空；不会删除用户随后复制的其他内容。清理依赖程序事件循环，无响应或被强制终止时不能保证定时执行。
- 关闭窗口不立即清掉刚复制的验证码，方便切换到网站粘贴；原计时仍继续。停用插件／程序退出会清理本插件仍持有的剪贴板内容。
- 用户原先从其他软件复制的密钥、系统已有剪贴板历史、第三方剪贴板工具和输入法不受本插件控制，不会擅自清空整个系统历史。未使用真实密钥测试。
- 验证码依据系统Unix时间生成，与本地时区无关；不匹配时检查操作系统时间，插件不联网校时。
