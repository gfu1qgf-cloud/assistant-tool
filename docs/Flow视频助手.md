# Flow 视频助手（本机试用版）

当前主程序插件版本 0.4.19，桥接扩展 1.1.16，基于固定版本 FlowCue 1.1.4。修复第一条已保存、网页队列仍在收尾时过早提交第二条的问题；等待网页明确空闲后自动继续，托管批次最后一条不再等待“下一条”倒计时。保留积分检测、连接确认和原媒体恢复修复。主程序下次正常重启生效；扩展等该浏览器的云端任务和下载结束后重新加载并刷新项目页，无须重新配对。真实网页完整流程及下载弹窗仍需实测。

主插件 0.4.19、扩展 1.1.16：修复旧的参数摘要核对失败和准备超时禁用标记长期占用浏览器、导致并行账号不足。最新扩展在准确项目上报告控件就绪、网页空闲且同账号没有未决任务后，每个连接最多将这两类明确未提交旧错误转回一次参数核对；保留原禁用原因历史，不把清除标记当作参数验证成功，不自动启动暂停队列。准备等待上限由 60 秒调为 110 秒，超时和设置控件缺失最多自动重试三次；登录、网站限制、实际选中参数不一致及结果不明的生成继续保留保护。设置每个字段时重新定位当前可见面板，结束前等待实际选中控件稳定，避免模式切换重建面板后仍操作旧节点。

入口：插件 → Flow 视频助手；任务列表多选后右键 → Flow 视频助手 → 生成 Flow 视频。

## 首次连接

1. 在“浏览器与时长分档”双击配置行，或在连接向导选择配置，点“① 打开浏览器并连接”。项目地址可以先留空。
2. 程序先检查扩展。未安装／未启用／需更新时，自动打开所选配置的扩展管理页和扩展目录，并复制目录路径；按页面提示加载／启用／重新加载，再点“安装／更新完成，打开 Flow”。已安装的直接打开 Flow，不必倒回去准备配对配置。
3. 第一次请在这个浏览器进入要用的 Flow 项目，复制地址栏网址（Ctrl+L、Ctrl+C）。向导仅在这一步、当前所选配置的五分钟等待期内识别有效的 Flow 项目链接，自动保存项目，再打开扩展设置自动填写并保存连接，无需粘贴配对信息或再点保存。切换配置、关闭面板或超时后停止识别。不会把旧剪贴板内容或别的网页猜成项目；已有保存地址时直接使用。
4. “③ 连接备用操作”保留可见的“复制配对信息”和“打开扩展设置”。没有有效项目地址时复制按钮禁用；填写有效地址后点击可先可靠保存、生成并复制配对信息，再在扩展设置手动粘贴保存。默认自动流程不把长期配对密钥写入剪贴板。
5. 接口显示已连接后即可提交。允许自动启动的配置组在下方选择并保存一次；之后自动调度时长、按需启动浏览器、连接已保存的项目并下载成品。主程序和浏览器可任意一方先启动，断线会重连；网站登录仍由用户完成。

自动启动只使用所选配置组中明确保存了有效项目地址的配置；不再轮流唤起大量未配置的浏览器、分配时长档或反复弹向导。未配置时，排队原因提示添加地址。对已配置的备用浏览器先检测：缺扩展、停用、版本需更新或无法确认时进入对应连接向导；已启用且版本匹配则正常启动，不反复配对。

也可从“浏览器与时长分档”选择一行后点“连接／安装扩展…”进入对应配置的向导。“只检测安装状态”不会保存设置、启动浏览器或提交生成。检测在工作线程中只读 `Preferences`／`Secure Preferences` 内此扩展 ID 的安装记录，不修改 Chrome 文件；在线连接是更强的已安装证据，离线不是没安装。无法读取、记录矛盾或只有扩展文件时显示“无法确认”，引导检查，不冒充确定未安装。

已在线且保存的是同一项目时，“打开浏览器并检查”只打开项目、检查状态，不重新配对、不暂停接单、不重复读取已知积分。更换项目或主动重新配对时，正在生成、上传、下载、归档或结果待核对的配置会拒绝修改，避免打断。自动配置通过限定扩展来源的本机 WebSocket 领取单次、两分钟有效的连接票据；票据领取不授予生成权限，长期密钥不进 URL、命令行、普通日志或导出文件。手动备用粘贴只填表，仍需点保存；用户主动复制的配对信息未被替换时两分钟后清除，退出时也会清除，系统剪贴板历史可能另行保留。

首次本地加载步骤仍由用户在 Chrome 中确认，向导不使用企业强制安装策略、不修改 Chrome 安全设置。扩展配对页按 [Chrome 官方选项页机制](https://developer.chrome.com/docs/extensions/develop/ui/options-page) 提供。

扩展固定 ID：`pnjppjjfgiccpcfajkpooklgohgihdom`。本地服务默认只监听 `127.0.0.1:18189`，所有浏览器共享此端口，以稳定浏览器 ID、批次 ID 和请求 ID 分流。配对码保存在主程序插件私有数据中；无需 Google 密码。

## 生成任务

在主程序加载任务表后，从“插件 → Flow 视频助手”打开，面板会直接读取当前表中的全部任务。在“任务编号”处搜索编号或名称，再从下拉框选择任务，下面会显示任务名称、目录和该任务的图片；不是让用户填写路径。点击“刷新任务”可重新读取主界面当前已加载的任务表，不会修改已提交队列。

也可在任务列表多选，右键“生成 Flow 视频”，只读取所选任务，默认选中第一条。右键入口的“全部任务图片加入清单”仍只作用于本次所选范围，不会擅自扩成整张表。需要其他任务时点击“刷新任务”读取整张表。

首次用连接向导为每个浏览器配置单独保存、配对此账号的项目地址，以后连接主程序时自动打开专用项目页，不用反复手动打开网页。原扩展已经明确保存的地址可在其连接时记入主程序，不会把当前网页冒充保存地址。选择“只使用已连接浏览器”时不自动启动新浏览器。主程序启动本身不会恢复旧队列的付费生成，仍需明确继续。

### 手动逐条提交

选择所属任务和任务图片。右侧显示完整比例的图片大预览，不裁切，并标明任务、文件名、尺寸和完整路径。切换任务时分别保留提示词草稿；参考图刚刚被替换时会刷新预览，确认后再提交。

在大文本框填写本条提示词，选择时长、比例、分辨率、数量和积分预算，点击“提交这一条”。这一条先可靠保存到队列，再自动分配浏览器、生成、下载和归档；不会因此启动其他未放行的批量任务。提示词保留，方便继续修改、逐条提交。一次选择多个输出时会展开为独立任务。

主程序重启、点击“暂停后续任务”之后，尚未提交的条目仍然保留，但不再自动放行。可在队列中选择需要的条目，点击“只提交选中项”，或点击“开始／继续”放行整个队列。网站验证触发的安全暂停不会被新建手动任务绕过。

### 批量添加

“批量添加任务”保留原来的清单模式：可选图片加入清单，也可加入全部所选任务目录图片；提示词双击编辑或批量应用。批量保存与手动保存分别确认，不会互相清空草稿。

默认“提交并生成”：可靠保存后自动放行本批新任务，不连带启动其他旧等待项。勾选“仅保存，暂不生成”时才需要以后明确开始。安全暂停不会被提交绕过；重启后旧队列也不会擅自付费执行。

所有分页顶部显示已连接、可接单和执行中浏览器数量，以及当前排队原因。点击“查看浏览器状态”可逐一看到扩展连接、页面响应、账号、积分、分档及下一步。只有扩展握手不算项目就绪；页面心跳失联会撤销就绪状态，不再保留旧的“已连接”误导。选中项的低频编辑／恢复操作集中在菜单和右键中。

参数核对直接读取设置面板已选控件，不要求收起后的摘要同时重复模型、比例、分辨率和数量。不使用未选选项或请求写入的 store 值冒充实际选择；无法确认哪一项时明确说明，暂停该浏览器而不盲目提交。

读取积分会关闭账号弹窗，因此准备任务和真正提交前会主动重新核对当前账号；只采用本次打开账号面板时确认的唯一邮箱，不会因弹窗已关闭就把账号认成空值，也不会借用历史邮箱继续付费生成。

模型固定为 Omni 1.1 Flash。每图数量会展开为独立任务，方便单独重试。时长默认使用模型自身设置；显式选择秒数时，网站不支持该秒数就报错，不自动换另一个秒数。比例支持 9:16／16:9，分辨率支持 720p／360p。

保存后先写队列，再派发。点击“开始／继续”执行，关闭面板继续处理。程序重启后保留任务，等待再次点击开始；曾提交但结果不明的任务先核对原浏览器，不直接再次生成。

“最多并行账号”允许 1–8。选择已有 Chrome 配置组后，账号积分不足下一条时，可按有限候选列表按需启动其他配置；每轮每个配置最多启动一次。相同 Google 账号的多个窗口不会重复计算可并行额度。未能确认当前 Flow 登录账号或积分时显示未知，不把 Chrome 配置名称当成登录账号。

### 浏览器时长分档

需要单独检查积分时，在“浏览器与时长分档”选中一行或多行，右键“检测选中浏览器积分”。无需创建生成任务；只检查所选在线浏览器。积分栏会显示“检测中”、检测成功的时间，或明确失败原因；失败时保留的旧余额会标记“上次”，不是本次检测成功。浏览器未连接时先连接该配置；同账号正在执行任务时会提示完成后再检测，保持当前任务。顶部原有“刷新账号积分／核对中断任务”仍提供全局刷新。

默认“自动分配”：优先使用同档和允许补位的通用浏览器；没有匹配时，将空闲自动配置切换为所需 4／6／8／10 秒并接单，离线的已配置浏览器也可自动安排时长后启动。旧版在首次接单后写入的时长不再永久锁定；无需用户为每种时长提前手动分档。优先处理已有同档任务，避免来回切换。

正在生成、上传、下载或结果待核对／下载失败的浏览器及同账号均不改档、不接新生成；未配置项目地址的浏览器不猜地址。需要严格专用时，在浏览器表格明确选择“固定 6／8／10 秒”或固定通用档；也可切回“自动分配”。关闭全局自动分配后保留严格匹配规则。“模型默认”只使用通用档，不猜测时长。

某档正在等待账号时，不阻挡其他任务。按用户明确指定的固定规则计算 Omni 1.1 Flash 每条视频费用：6 秒 10 积分，8 秒 12 积分，10 秒 15 积分。费用估算、余额判断、最小足额账号选择、备用配置启动及整批额度预留统一使用该规则，不依赖这三档的网页费用读取，也不被旧的页面费用缓存覆盖。账号可做几条由剩余积分决定，不写死生成次数。

账号连接时读取一次积分，之后在发送生成前按本条费用保守扣算，多个同账号窗口共享估算；不每分钟、不每条、不在下载重试或完成时反复打开账号菜单。界面标注本地估算，结果不明确时不自动返还积分。重新连接或主动“刷新账号积分”可核对网站余额。页面可见账号变化仍阻止误投，网页自身或其他软件消费的积分无法仅靠本地计算获知；网站实际余额不足时暂停该账号而不重复生成。

积分预算为 0 时按上述固定规则自动计算；非 0 是单条预算，低于固定费用时保留排队，不擅自放大预算。4 秒与“模型默认”没有用户指定价格，保留页面读取和明确手动预算，不猜成 6／8／10 秒。这些数值是用户设置的本地调度规则，不代表 Google 实时账单，也不能约束网站实际扣费。每次生成前仍核对 Omni、时长、比例、分辨率与单次输出数量；网站要求安全验证时仍暂停。

升级后只解除已知三档因旧“页面费用无法读取”导致的环境暂停，不清除其他模型、登录或安全错误；旧任务仍等待用户点击开始／继续，不在程序启动时付费提交。

## 下载、归档与重试

如果旧记录显示“等待原浏览器核对”，详情精确为“插件队列正在运行，请先停止”，可在更新后选择该条点“重试选中”。程序只对没有媒体绑定、原生成响应、下载等提交证据的接收前拒绝项恢复排队；保留历史并撤销该次未提交的批次预算预留，不凭空补回账号积分。暂停的队列仍须明确开始／继续。响应超时或已有生成证据的项继续核对，不因此重新生成。

### 自动连接与页面恢复修复（0.4.6／1.1.5）

正常操作在软件点击“打开浏览器并连接”，会直接打开本配置已保存的 Flow 项目。一次性连接票据放在项目 URL 片段里，由扩展隔离脚本交给后台领取配置；网页拿不到主程序长期连接密钥。已有连接优先复用项目标签页，不反复新建；开页不再改写连接配置，也不因相同配置的存储通知反复重连。

设置页单独打开时会尝试已保存配置自动重连，不再直接停在“没有自动入口，请粘贴”。后续连接入口变化会继续自动处理。扩展源码已更新而浏览器仍载入旧版本时，更新必须由主程序近期连接请求授权，确认没有受管生成／下载后重载扩展，并刷新原项目恢复连接。手动配置保留为可选入口，不是正常流程的一步。正在运行的旧主程序不会热重载；本次修改两端后需统一载入新版一次。

桥接不再改写网页的全局 Object.prototype，也不主动遍历执行全部 Webpack 模块。这是针对可复现风险的收敛，不代表已经验证所有浏览器卡死的根因。

当前版本遇到“生成响应未解析到媒体编号”只对原任务做最多三次只读快照核对，提交后不会自动刷新项目或重新点击生成，也不下载相似视频。仍缺少编号时保留“待核对”并继续接收原任务迟到结果。新失败响应保存在主程序加密诊断库（限量），便于修复具体接口格式；不需要为收集诊断重新付费生成，不把大响应反复传入界面。

### 本次修复（主程序插件 0.4.5／桥接扩展 1.1.4）

桥接模式只接受本次生成请求响应给出的媒体编号，不再从页面新出现的卡片、相似提示词或“唯一一个视频”补认领。下载及落入任务目录前都核对任务 ID、提交 ID、媒体 ID 与就绪绑定；身份不明则保留下载、提示核对，不自动换视频或重新付费生成。已有确认绑定不被后续不同媒体的快照覆盖。

下载通知早于快照到达时会自动等待、请求原项目快照，核对成功后继续归档。旧版本已经保存、但缺少生成响应来源证据的绑定不自动升级为可信结果；此前下错的视频保留，不冒充已修正，也不从原项目任意挑一个视频顶替。

“打开扩展设置”会生成新的自动配对入口，不再只打开没有票据的空设置页。保存配置与连接成功分别显示：后台收到主程序确认且配置一致才显示“已连接”。扩展重连中旧连接的迟到关闭事件不再破坏新连接。直接从扩展工具栏进入设置页、没有自动入口时，也会明确说明下一步。

普通更新不需要退出软件进行隔离测试；主程序下次正常重启载入新源码。扩展在浏览器空闲后到扩展管理页点一次“重新加载”，再刷新专用 Flow 页，载入新桥接代码。不自动重新提交旧任务。

### 删除任务记录

在全局队列多选后点击上方“删除记录…”、右键“删除选中记录…”或在队列表格内按 Delete。手动面板的最近提交也支持右键删除这一组记录。“选中项操作”还提供“清理已完成／已取消记录…”。均需确认，默认按钮是取消。

只删除队列、最近提交及相应运行历史；任务图片、成品、浏览器下载文件、逐图草稿均保留，不删除云端媒体。执行中或文件后台保存中的项会保留，其余可删除。待核对／下载失败的记录默认保留，只有用户在原网页确认云端结束、明确勾选放弃恢复记录后才删除；删后无法再通过该记录恢复下载。

删除不会退回整批积分预留；保留最小的费用、提交去重和已删除批次标识，防止删除已付费记录后突破批次上限，或迟到的浏览器回包使任务复活／重复生成。软件不会因为安装更新而自动替用户删除现有记录。

### 下载与恢复

图片上传或视频下载失败后，默认分别自动重试最多 5 次（不含最初一次），间隔依次为 5、15、30、60、120 秒；更多次数保持 120 秒。“连接与设置”可分别设置 0–10 次，0 为关闭自动重试。列表详情显示次数、下一次倒计时和等待原浏览器／登录的原因；断线等待不消耗重试次数。相同任务不会同时启动多次传输，迟到的超时和失败回包不能覆盖新一轮。

队列上方有独立的“重试下载”按钮，右键有“重试下载（不重新生成）”，手动面板的最近提交也有对应按钮。手动重试可重新开启一轮已用尽次数的下载恢复，不会重新生成视频；不再只藏在“重试选中”中。

下载优先使用数据库中持久保存的原媒体 ID、提交 ID、下载路径和原地址；即使网页刷新后临时任务丢失，也不依赖页面还保留那一行。浏览器会先检查该批次是否已有完成／进行中的下载，避免重复下载。页面的空快照不能清除已保存的完成绑定。只有缺失原绑定、原浏览器不可用、链接持续过期或超过次数时才需要检查；不根据相似画面猜视频，不触发新的付费生成。

重试次数与阶段进度持久保存；重启后已生成视频可继续恢复下载。未付费提交的上传等待用户继续队列后恢复，已发送／结果不明确的生成请求不会自动再发。暂停后续任务不打断已有成品下载；原图变化、账号变化或安全验证会停止自动上传。上传成功只进入原来的单次提交入口，整批预留仍按原尝试去重。

Chrome 先下载到浏览器默认下载目录的 `FlowBridge/<批次ID>/result.mp4`，随后主程序校验视频并复制到提交时固定的任务目录。默认下载目录与系统下载目录不同的，需要在连接与设置中选择实际目录。

Chrome 遇到同名文件自动改成 `result (1).mp4` 等编号时也能归档；仍须在原批次目录内、下载完成且具有媒体／提交绑定，不接受其他目录或任意文件。

任务成品命名为 `Flow_001_图片名.mp4`，序号按加入顺序固定。已有文件不覆盖；归档中断后校验同内容文件即可恢复。浏览器下载原件保留，后续可由用户自行清理。大型媒体不进入插件私有数据目录。

- 重试选中：未提交失败项可再执行；有媒体绑定的失败项只重试下载；已下载完成的失败项只重试归档。
- 等待原浏览器核对：先打开原浏览器并刷新账号／核对任务。如果明确接受重复扣积分风险，右键该任务“确认放弃核对并重新生成”。
- 取消等待项：只取消未提交的排队任务。已提交的云端生成保留状态。
- 下载未完成前，该浏览器保留原任务绑定，后续任务不会清空它。

批次结束后仍可“重试选中”下载已绑定的结果；该操作不重新生成、不恢复生成队列。更新扩展代码后，请在 `chrome://extensions` 对此扩展点“重新加载”，再刷新其专用 Flow 项目页；主程序源码更新在下次正常重启后生效。

桥接模式不再在每两秒的视频卡片扫描中逐个调用 `scrollIntoView()`。只有当前任务已绑定且就绪的媒体，按任务 ID＋媒体 ID 定位其视频卡片一次；不把页面底部、最后一个卡片或相似提示词当作“最新视频”。保留悬停唤醒、媒体状态检测和下载；后续扫描不再反复拉动页面。Flow 网页自身在实际提交时的布局／滚动行为不由此改写。

## 验证范围和维护

### 大批量队列与手动操作（0.3.0）

- 备用账号按是否能承担下一条费用判断，不再用“浏览器在线数量”挡住接替。同账号的重复窗口不增加可并行名额；尚未读到费用时不会把零积分账号当成可用账号。
- 模型／时长核对失败会暂停该浏览器，任务保留排队。到“浏览器与时长分档”选中它，修正网页后点“修正后恢复选中浏览器”。刷新积分不会偷偷清除环境错误暂停。
- 手动和批量面板都显示展开后的总视频条数、已知费用估算与费用未知条数，并可填写本次提交的整批积分上限。在发送生成请求前，数据库事务原子预留额度；结果不明仍占用预留额度，不自动退款或再次生成。队列按提交批次显示预留／上限，选中条目可调整本批上限。
- 这里的积分是提交前估算／保守预留，不是 Google 最终账单。用户指定的 6／8／10 秒固定费用可用于整批上限，账目单独标记“固定时长计费”，不冒充网页费用。其他未知费用有整批上限时仍不提交；无整批上限时才允许按明确单条预算预留，并单独标注。旧队列不补造历史积分账目。
- 队列支持按提交批次／所属任务分组，状态筛选、搜索、未提交项编辑和优先级。可多选统一修改参数；默认各自保留提示词，只有明确勾选时才统一替换。已开始的任务不允许修改，整次多项修改先校验再原子保存。重试全部失败项只放行失败后重新排队的条目，不顺带启动其他等待项；已有媒体只重试下载／归档。待复核成品不会被此按钮重新生成。
- 等待原因直接显示在详情栏，可打开对应浏览器。生成／下载长时间无进展时，先自动核对原任务并在已确认媒体就绪时仅重试下载；仍不明确则列为待处理，绝不自动重新生成。默认 20 分钟，可在连接与设置调整。
- 下载长期失败时，核对云端生成结束后，可“暂存下载并释放账号”。保留原媒体 ID、提交 ID、项目地址及下载绑定；原浏览器可继续下一条。以后“重试选中”只恢复原媒体下载，不替换当前生成批次。签名链接可能过期；可打开原项目核对，通过右键“更新原媒体地址”提供同一媒体的新地址。只接受原 Google 媒体 ID，不允许借此换其他任务的视频。
- 草稿按任务目录＋图片分别保存到插件私有 SQLite 存储；输入停止约 450 毫秒后自动保存，切图、关面板和正常退出时也提交保存。提示词和参数分别记忆，重启后选择相应图片恢复；“复制上一张提示词”只在主动点击时复用。
- “提交这一条”保留当前图片；“提交并切换下一张”／Ctrl+Enter 必须等入队成功回执后才切换。普通回车仍换行，失败不清内容、不切图。重复提交会提示查看原任务或明确再生成变体；相同提交请求重复到达不会重复建队列。
- 输入旁显示最近提交的图片、任务、时长、数量、提示词摘要和状态；同次多个成品可在下拉框分别选择。新成品使用主程序公共播放器就地预览、拖动进度，不渲染、不重新下载。旧记录缺少时长元数据时调用系统播放器。可逐个标记采用／待调整，或恢复原图片和参数“再做一版”。
- 归档除验证可播放外，还核对显式时长、画面比例和最低分辨率；异常成品保留为待复核，不删除、不重新生成。队列显示下载盘／任务盘空间；生成前和发送生成请求前会再检查，空间不足则停止新增生成。下载和大型成品不得放在程序绑定的加密数据卷上；队列、草稿、媒体绑定等私有记录仍由主程序保存到密盘。归档空间不足时保留下载，待释放空间后仅重试归档。
- 下载副本默认保留。可在连接与设置启用“归档校验成功且无异常后自动清理”，或在队列右键手动校验清理。只清理已采用／通过核验、与任务成品校验和完全相同的本批下载副本；不动用户原图、其他下载或任务目录成品。

上述流程使用隔离队列、合成媒体和模拟扩展验证，不使用真实账号或积分。真实 Flow 网页的可用时长、费用显示与登录面板仍以实际页面为准；修复环境后需用户明确恢复，不绕过网站验证。

本版已验证持久保存、回滚、来源图片变化检查、相同账号互斥、本地认证连接、重启不重复提交、下载归属、跨目录复制校验、同名不覆盖、UI 工作线程关闭，以及不消耗积分的模拟浏览器到真实合成 MP4 归档闭环。另覆盖手动单条放行、暂停／重启不误提交、提示词与图片归属、完整预览、按时长分档路由、离线配置启动匹配，以及分档编辑不被旧快照回退。尚未用用户 Google 账号提交真实生成；Flow 页面选择器、费用显示和账号面板仍需首次实际使用核对。
