# OpenAI / GPT 聊天（试用台 1.5）

入口：程序设置 → AI 模型试用台 → 服务商选择 OpenAI / GPT。聊天窗口的连接设置复用同一面板。

1. 在 OpenAI API 平台的额度所属组织／项目中创建项目 Key。
2. 粘贴到软件的密码输入框，保存。留空保留现有 Key，勾选移除才删除。
3. 回到对话，服务商选择「OpenAI / GPT」。软件自动在后台读取账号模型列表；`gpt-6-luna` 只是默认填写值，不表示只有一个模型。也可手动刷新或填写支持 Responses 的具体聊天模型 ID。
4. 输入文字或添加图片后发送。可继续多轮对话、流式输出、停止请求及手动重试。

切换模型影响下一条提交，不会改变已经提交的请求，也不清空历史上下文。每条回答下方和完成状态显示“请求模型／接口返回模型”，来自请求与响应元数据，而非回答正文里的自我介绍；接口未提供模型 ID 时明确标注未提供，不用请求名冒充确认。历史中的旧模型回答可能影响新回答的自述；需要独立比较时新建对话。

Key 使用 Windows 当前用户 DPAPI 加密，保存在既有 AI 服务密钥配置中；也支持 `OPENAI_API_KEY` 环境变量。不会写入聊天记录、节点参数、源码或共享表格。更换电脑／Windows 用户后需重新填写。

只连接 `https://api.openai.com/v1/models` 和 `https://api.openai.com/v1/responses`，禁止重定向至其他服务器。不调用第三方路由、不自动换模型、不自动重发聊天请求。使用 `store:false`，不创建服务端持久会话；这不等于云端零保留，仍适用账号与官方数据政策。

模型列表不保证每个模型都有调用权限，也不保证支持图片；API 没有提供的模态／价格信息不作猜测，不把赠送额度标记为模型免费。手动填写模型直接调用，不因 Key 缺少模型列表权限而阻塞聊天。输出上限包含模型推理 token；若只有推理没有可显示文字，会报告未完成，可手动提高上限。

程序设置一次只显示所选服务商的输入；切换保留尚未保存的字段，最后统一保存。OpenRouter／Cloudflare 专属筛选放在各自配置中，Gemini 继续使用原密钥管理器。

有 OpenAI Key 时首次显示该服务商自动查询一次，失败不循环重试；页面明确显示模型数量、尚未读取或实际失败原因。修改密钥后重新查询，旧 Key 的迟到结果不会覆盖新 Key 的列表。查询模型仅调用 Models API，不提交聊天、图片或付费生成；手动刷新始终可用。

调用计入 API 组织账单，赠送额度、到期和余额以平台为准。已有付费余额时可能继续扣费；本功能不是硬性美元预算控制器。不会增加 ChatGPT／登录版 Codex 使用额度，此聊天入口不支持 Codex、语音、生图等非文字聊天模型。

真实 Key 需要用户在本机软件输入。回归测试使用模拟响应与虚构密钥，不代表已验证实际账号连通或可用额度。

官方协议：[文本生成](https://developers.openai.com/api/docs/guides/text)。
