# 图片／视频控件的循环交界（1.29）

底层背景和画面中叠加的视频控件分别控制循环。过去的项目设置“循环交界”只作用于底层背景，视频控件的循环是直接衔接。

现在选择图片／视频控件，在控件属性的“素材不足时循环”下面：

1. 保持“素材不足时循环”开启。
2. 将“循环交界”改为“叠化”。
3. 设置“叠化时长”，默认0.3秒，0关闭。

只有素材比所需显示时间短、需要重复时才叠化。图片不产生循环交界；关闭循环的视频仍播完隐藏。“入场与退场”控制出现／消失，和每次循环的叠化分开。

设计画面显示素材首帧；点击“播放预览”观察实际循环交界。原生控件、转换后的节点效果、节点预览和正式导出使用同一套处理。

绿幕、辅助遮罩和AI精修先应用到画面，再叠化透明前景，不会把绿幕混回边缘。内存仅保留叠化需要的少量首尾帧，先按实际控件画幅缩小，缓冲每路最多256MiB，其他解码／推理工作帧另计。过长的叠化会根据素材帧数和缓冲上限自动缩短；每次重复的有效周期会减去重叠部分。取消后释放缓冲和解码进程，不保存整段透明MOV。

旧项目继续使用直接衔接，手动选择叠化后随项目保存。
