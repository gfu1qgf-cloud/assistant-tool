# 图片背景与缩放动画（1.30）

纯图片可以直接作为最底层背景，无须先制作背景视频；可以与文字、抠像图片、字幕、人声、音乐和节点效果共同合成。

## 使用位置

1. 在“资源 → 添加背景视频／图片…”选择图片，或把图片直接拖到左侧“背景”池。这里支持 PNG、JPEG、JFIF、WebP、BMP、TIFF 和已有的视频格式。
2. “批量 → 搭配资源”将背景与文案明确搭配。背景池允许混合图片与视频，自建图片池、视频池、视觉池也可以在搭配窗口中明确选作背景。单纯浏览自建池不会替换底层背景。
3. “项目设置 → 画布与背景 → 背景池”是全项目的底层背景来源。选择池后按队列顺序循环取用，预览不消耗轮换进度；选择“按任务已搭配背景”时沿用各任务已有的背景绑定。
4. 左侧切到“图层”，点击最下方“底层背景 · 视觉控件”，在右侧“控件属性 → 动画”调整效果。普通图片、视频视觉控件也使用同一套动画参数，各控件互不影响。项目设置中没有动画参数。

| 参数 | 行为 |
| --- | --- |
| 无动画 | 保持适配画布后的图片 |
| 呼吸 · 平滑缩放 | 按每次循环的周期反复放大、缩小 |
| 先向外放大 | 从适配尺寸开始放大，再缩回适配尺寸 |
| 先向内缩小（预先放大） | 首帧已放大，先缩回适配尺寸，再放大 |
| 缓慢推近 | 在单程用时内放大，完成后保持 |
| 缓慢拉远 | 首帧已放大，在单程用时内缩回适配尺寸，完成后保持 |
| 强度 | 最大放大百分比；例如 8% 对应 1.00～1.08 倍；0 为静止 |
| 每次循环 | 呼吸等循环动画的周期；与强度独立，秒数越小越快 |
| 推近／拉远用时 | 0 跟随完整成品时长；指定秒数时在该用时内完成，随后停留 |

新视觉控件默认无动画，开启后可选律动、呼吸、推近和拉远；普通叠加视觉还可选择上下浮动。呼吸方向只在呼吸模式可调。底层背景动画也可用于视频背景。每个视觉控件保存自己的动画参数，支持撤销、重做与项目保存。

## 黑边与画面裁切

所有缩放模式的最小倍率都是适配尺寸，绝不会缩得比适配画布后的图片更小。向内呼吸和缓慢拉远通过首帧预放大提供缩小余量。

需要整个画布始终没有留边时，选择“画面 → 铺满导出画布（会裁边）”。“完整显示”保留图片全部内容，图片与画布比例不同时原本就可能留黑边。图片不执行视频多时刻黑边检测。

## 时长和预览

- 有已启用、已分配的人声：成片时长跟随人声。
- 无人声：使用“项目设置 → 时长适配 → 固定／图片时长”，默认 15 秒。即便长度方式为“视频原长／图片用下方时长”，图片也使用这个秒数。
- 拖动画面下方“动画快览”时间条，可以直接查看图片背景的缩放位置，不需要先编码整片。
- “播放预览”和“快速预览”均生成包含图片动画的可播放短片。快速预览只限制编码长度，不改变缩放速度或完整项目时钟。

## 处理与验证

图片只解码一次，处理 EXIF 方向、嵌入色域和透明背景后，使用一张临时 PNG 输入；FFmpeg 在内存中重复已适配的一帧并直接合成最终 MP4。不会为图片背景生成循环视频或透明 MOV 缓存。临时图片会随本次渲染准备目录一起清理；原图片保持不变。播放预览沿用现有预览缓存机制。

专项测试覆盖图片单独导出、控件参数归属、全局背景池、控件之间独立、撤销、强度与速度、方向边界、配音时长、缩放归零、EXIF、透明图片、明确导入／批量搭配及图片首帧预览。实际 Python 3.10、Qt 与 FFmpeg 另验证双方向呼吸、无新增黑边、72 帧／2.4 秒输出、播放预览、节点叠加、时间条快览，以及明暗主题下控件属性和项目设置的布局。
