# 素材 AI 内存抠像（1.27）

选择图片／视频控件，在「控件属性 → 抠像 → AI抠像工作台…」打开当前素材。资源池来源会打开当前试看的素材；顶部「抠像」菜单仍可使用。

工作台显示透明棋盘、合成、黑白遮罩及原图对比。视频工作台显示首帧，完整动态效果使用文案视频的「播放预览」。画笔固定在素材坐标，不跟踪运动。参数与画笔支持 Ctrl+Z、Ctrl+Y。

点击「保存参数并用于此素材」只保存原素材指纹和抠像参数。资源池轮换时自动使用对应素材的参数。默认不生成透明 MOV／PNG 中间文件。停用已存结果或关闭控件里的「优先使用此素材已保存的抠像结果」，可恢复原素材。

- 设计画面：在内存生成抠像首帧，最多保留 32 MiB 的缩略预览。
- 播放预览、正式导出、节点模拟预览：读取原素材，逐帧推理、精修，通过 Windows 内存管道直接送入最终合成。管道背压限制待处理帧数量，不把整段视频载入内存。
- 每次渲染重新推理；长视频在 CPU 上会增加渲染时间。图片在一次渲染中只推理一次，随后复用该帧。
- 视频循环重置 RVM 的时间记忆；不循环时素材结束即隐藏。取消、推理异常和编码重试均释放或重建管道及解码进程。
- 保存／提交时冻结素材和参数，提交后的参数修改不会影响已提交任务；原素材发生变化时明确报错。

「另存透明结果…」仍可主动导出 PNG／MOV。只有这一操作才生成独立透明媒体文件，MOV 采用无损编码，体积可能较大。

旧版已保存的透明结果继续兼容。打开旧素材，重新点击「保存参数并用于此素材」即可改为动态抠像。旧透明文件可能被已保存的工作流引用，因此升级不会自动删除这些文件。AI 模型文件和合成后的视频播放预览沿用原有存储方式。

实现说明：插件的 StreamInput 在编码开始前展开为有界原始 RGBA 管道。节点结算与单帧预览通过可信编译器设置的 deferred_input_factory 管理相同的输入生命周期；未设置时沿用原行为。
