正式源码修复
1. 普通冷启动配对不再因为“浏览器尚未连接”就改为内部扩展设置页，而是打开带一次性入口的原 HTTPS 项目。主动打开设置、旧扩展更新、在线原页复用仍保留。Flow 主程序插件 0.6.30；扩展继续使用已复审的 1.1.60，无热覆盖正在使用的扩展。
2. 图片检索索引每次事务结束后在创建该连接的线程内关闭 SQLite 句柄。保留提交／回滚及存储校验，修复 Windows 下文件持续占用、临时目录不能清理的问题；初始化失败也关闭连接。
3. ElevenLabs 只读权限检测晚于 Qt 界面销毁返回时，只丢弃属于已销毁信号对象的结果，并释放其模块持有引用；不是吞掉所有异常。正常活窗口回传、取消与代次校验保持。
4. 快速预览时长在读取配置、建立缓存会话前校验，无效值或正式导出传入限制及时报清楚的 ValueError；不能截短正式视频。
5. 视频压缩节点的属性编辑器改由已有 GUI 适配层注册，公共节点执行核心不再导入 PYUI。编辑器、参数、构建函数仍相同，命令行执行和工作区 UI 各有回归覆盖。

测试维护的依据（不是删除安全断言）
- 下载已确认完成生成后进入独立后台下载状态，恢复仍保留原媒体／执行号并实际发送下载请求；不回到生成队列、不重新付费。任务名额与物理浏览器窗口上限分别验证。
- 旧图片历史不能永久锁住没有实际在途任务的账号。测试同时验证真实在途图片保护、同账号并发互斥、已有账号优先、最多填满空闲恢复名额以及不无限补开窗口。
- 高积分授权不能越过正在进行的余额核验，测试给出真实合成回执后才允许派发；不把“授权”当成“页面与余额已经就绪”。
- 剪贴板通知按 Qt 事件循环有界等待。GUI 布局测试适配扁平控件属性和新的资源池操作栏；仍检查控件可见、按钮可用、数据不丢失。
- 老渲染器 mock 使用明确的函数接口，避免 Mock 自动生成 prepare_export 后误走新并发协议；测试任务具备有效名称和独立输出目录，不能以覆盖源文件的无效夹具要求程序继续。
- 缓存版本断言对应当前分数遮罩缓存；配置复制比较经过保存规范化后的真实配置，并另核对字号、描边等用户字段。
- Qt 生命周期静态守卫仅增加逐条核实的非 QThread 完成信号：GUI 对话框、动画、管理器任务句柄和 QRunnable 信号；真正 QThread 所有权检查仍保留。
- 只读存储重定向在构造时固定，测试改用构造参数；索引连接改为受控上下文后，断卷校验在实际进入上下文时验证，不能只创建一个不执行 I/O 的描述对象就要求报错。
- 使用真实画帧参数验证完整比例，而不是调用已替换的旧 QVideoWidget 接口。压缩默认质量30符合用户此前明确选择的配置。
