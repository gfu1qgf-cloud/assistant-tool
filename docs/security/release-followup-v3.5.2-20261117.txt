本轮定位与修正
人脸定位基线在本机独立复跑 5 次，均为 6912000 个 RGB 字节完全一致。
因此不能仅凭云端失败断言真实定位错误，也不宣称已查明差异的全部根因。
原测试先经生产有损 H.264 编码再解码，夹具还依赖宿主 CPU 线程数，不是
隔离几何的一致性条件。修正仅限测试夹具：lossless_composition 使用
CRF 0、单编码线程、明确滤镜线程；保留完整 RGB 字节严格相等，不加误差
容忍、不删断言。单与 4 滤镜线程分别检查；新增节点 x 偏移 2 个百分比
单位时必须不相等，证明真实定位差异不会被夹具掩盖。
同类透明裁边的严格成片比较复用该夹具；没有改变生产导出画质、线程、
滤镜、节点转换或实际人脸定位实现。移除一份同名而被 Python 覆盖的
重复测试定义，原有效用例继续执行，新增反向用例另计。
