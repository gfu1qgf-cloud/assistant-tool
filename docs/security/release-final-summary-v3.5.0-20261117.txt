  使用临时配置、禁网和静音合成媒体，未用真实账号或付费生成。

  固定Rust及各原生媒体库的版本、范围和限制见原始依赖报告。

1. 升级受影响的PDF、ASN.1、OAuth、文件锁、追踪API与Torch/TorchAudio，
   按批准的隔离验证结果固定组合，不盲目混装原生库。
2. Google授权增加连接截止和PKCE；ODS限制压缩/展开量；受保护路径统一
   检查；修复冷导入循环。
3. 文案视频修复无背景刷新、首次显示前预览丢失、字体几何缓存失效；
   Flow修复重复启动，保留项目/任务/请求身份和付费任务保护。
4. 修复真实EXE启动失败：构建误收其他工具的同名ICU DLL。现隔离构建
   搜索路径，实际EXE的界面、媒体与退出检查加入CI。
5. 扩展严格域名边界、Map批次去重、own-key回执；控制台不记录账号派生值
   或页面网址/配对片段，识别、积分、生成与下载逻辑保持不变。
6. 发行说明不再混入开发流水；流式ZIP有界内存、不覆盖已有包，失败只
   清理自有半成品；隐私、完整性及程序/独立扩展一致性均为发布门禁。

发布与隐私边界
只发布个人仓库gfu1qgf-cloud/assistant-tool，main正常快进、不强推，
另一个origin不动。纳入已获准且验证通过的既有开发功能。
正式附件包括Windows程序ZIP、匹配扩展安装ZIP、对应源码、SHA-256与
审核说明，并生成构建证明。程序ZIP也自带相同扩展。BUILD_INFO.json记录
版本、完整源码提交与实际依赖；正式附件由Actions重新构建上传。
不携带私人配置、凭据、Token、API Key、客户任务、成品、聊天、模型缓存
或组内资料。开发者文档仅留源码docs，不随EXE。不要把早期本机候选包当
最终正式附件；现用配置、恢复副本、任务数据不因发布被删除或覆盖。

明确保留的风险
- stable-ts已归档；替换原型与兼容评估已完成，但多语言/长口播业务验收
  未完成，未静默切换字幕算法。
- .pt2反序列化仍为条件风险，未发现调用torch.export.load；只加载可信
  模型。离线策略、节点和插件系统不是恶意代码沙箱。
- Flow debugger及Google媒体域权限仍强，未做真实付费服务全流程测试，
  网站变更可能影响自动化。系统剪贴板历史、转储、外部应用不在全面清除保证内。
- 系统Git已修复，本轮显式用2.56.1；Codex内置旧Git仍属供应商更新事项，
  不改签名应用文件，也不随程序发行。公开包无私人文件不等于本机所有旧
  副本已安全抹除。
