Git 开发工具链安全更新记录
日期：2026-11-17

结论
系统 Git 已从 2.51.0.windows.2 升级到官方安全版 2.56.1.windows.1。
本轮公开的六项 Git 安全修复均包含在该发行版中。
这不等于机器上所有嵌入式 Git 都已修复：当前 Codex 签名运行时中的
Git 2.56.0.windows.4 仍早于修复版，列为未关闭的宿主工具链风险。
先前应用安全审核侧重程序依赖与源码，遗漏了这项开发工具版本检查；
本记录将它明确补入范围，不修改旧报告的原始检测证据。

同批六项：CVE-2026-111760、CVE-2026-113408、CVE-2026-114466、
CVE-2026-114467、CVE-2026-114469、CVE-2026-105437。
GHSA 页面部分“Patched versions”元数据仍写 none；维护者正式发行说明
已经明确列出 2.56.1 与维护分支修复版，因此以发行说明判断本次修补版本，
不把聚合字段差异隐去，也不称它们全都能通过普通 status/log 触发。
其中 CVE-2026-111760 主要涉及攻击者控制仓库的递归子模块克隆。

应用官方更新检查返回当前配置通道 up_to_date，未提供可安装更新；
这只代表该通道没有合格更新，不代表其内置 Git 已修复。
一次尝试的应用升级命令被审批拦截，未执行；没有绕过审批或重启应用。
后续本次终端操作均显式使用已修复的系统 Git；不能由此推断 Codex 所有
内部 Git 界面也已切换。内置副本应等待官方运行时更新并再次核对版本。
在此之前避免通过仍用旧副本的应用递归克隆不可信仓库或处理不可信
二进制补丁、异常引用、复杂合并输入；不是只禁用子模块就修好了六项问题。
