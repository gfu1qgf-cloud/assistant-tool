六、剩余风险与后续
1. stable-ts 已归档。替代原型和兼容评估完成，但多语言、长口播、分词／
   换行的业务验收未完成；没有为追求升级静默改变字幕算法。
2. .pt2 反序列化仍为条件风险，未发现应用调用 torch.export.load。
   只加载可信模型；OSV 无命中不等于该公告已被证明消失。
3. 2 个主配置和 4 个可能活动的 Google 授权原文件仍有敏感特征，未被
   Git 跟踪、不在发行包中；必须进一步验证入口和恢复路径后迁移，不能
   仅凭已有加密副本就删除活动文件。普通删除不等于取证级安全擦除；
   若密钥确曾泄露，须到对应平台作废重建，本轮未擅自轮换。
4. 播放器曾出现间歇 setSource 挂起，额外五轮及后续全量未重现；不能
   宣称已查明或永久消除。Flow 保留强浏览器权限，未做真实账号付费全链路
   验证；网站变动、登录和平台策略仍可能影响服务。
5. 云端冻结导入有 pydub 未在 PATH 自动找到 FFmpeg 的警告。主视频链
   使用包内显式工具路径且已验证；音频分段插件在没有系统 FFmpeg 的
   非 WAV 场景仍待专门实测，不把导入成功当该分支的功能验收，也不为
   消除警告盲目改全局 PATH。
6. 原生媒体解析、恶意本地插件、系统剪贴板历史／转储及未知漏洞，不在
   应用层隔离保证内。Python 节点是需用户授权的本地代码能力，不是沙箱。
7. 全平台轮子哈希锁、受限子进程解析与恶意媒体模糊测试仍建议后续实施。
   系统 Git 已使用 2.56.1；Codex 内置旧 Git 仍由供应商更新，不篡改签名文件。
