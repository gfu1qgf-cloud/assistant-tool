# GPT 图片翻版 0.1.0

入口：插件 → GPT 图片翻版。凭据入口：程序设置 → GPT 图片翻版。

## 使用

1. 填写画面提示词，设置生成数量、创新程度、比例、质量与模型。
2. 如需保持固定人物形象，添加最多4张本地参考图；缩略图可双击查看完整画面，右键移除。没有参考图就是纯文字生图。
3. 选择输出目录，点击“生成 · 提交Batch”，核对数量、模型、参考图上传与付费提示后确认。
4. 程序先持久化输入，再排队处理参考图和提交云端。原提示词、每张最终提示词、参数、参考图快照、批次ID、结果映射均保留。关闭面板不取消任务；云端等待不占本地工作线程，可正常退出主程序。下次启动检查原批次，不自动重提。
5. 有活动任务时每5分钟检查，也可以点击“检查并收取结果”。待处理错误累计3次会暂停自动检查该项，修正路径／网络等问题后手动检查恢复；不会因此阻塞其他记录。

历史列表右键：查看提示词与错误详情、打开目录、沿用参数再做一批、仅重试失败图片、取消云端批次、删除已结束记录（保留成品）。提交响应不明时还有“关联控制台批次ID”备用入口，只接受元数据严格匹配当前作业与尝试的原批次。

## 创新程度

- 0：忠实呈现原始提示词，只允许轻微镜头变化。
- 1—30：主要改变机位、景别、构图及轻微光线，保留主题、场景和物件。
- 31—70：保留核心主题与人物关系，重新设计动作、细节、机位与光线。
- 71—100：保留核心寓意，明显重构场景与视觉表达。

创新是传给图片模型的明确创作规则，不是原生API参数，也不是可精确保证的差异百分比。有参考图时，人物身份与标志性外观的保留要求不随创新程度放开；实际一致性仍需人工检查。第一版由图片模型直接完成创作，不先调用另一轮文字模型，因此只有一轮生图Batch。

## 费用与恢复

仅使用官方 `https://api.openai.com/v1/batches`；无参考图走 `/v1/images/generations`，有参考图走JSON形式 `/v1/images/edits`。初版只提供已核对支持图片Batch的 `gpt-image-2.5-flare` 与 `gpt-image-2.5-sunburst`；具体账户权限仍由官方返回确认，拒绝时不会偷偷换模型或走普通计费。

每批1—500张，每张一条请求、固定 `n=1`。使用独立的 `custom_id`，结果不依赖返回顺序；每次重试生成新尝试ID，只包含已确认失败的图片。成功结果不会因为重试而重做。

Batch处理窗口为24小时，可能更早结束；不是本地线程运行24小时。费用按官方模型Batch价格与实际用量收取，批处理不代表少消耗Token，不保证赠送额度适用于具体账户。确认框不提供未经核验的固定价格。取消可能需要数分钟，已执行部分仍可能计费并会被收取。

网络超时或提交响应损坏时，先保存“提交待核对”，按元数据查询原批次；没有查到不等于没扣费，不自动提交第二次。已结束批次的下载错误仅重新读取原结果文件，不触发生图。部分结果损坏也会先收取其他健康图片。整批过期／失败时保留成功部分，其余明确标为失败；只在用户确认后重做。

OpenAI Key复用宿主加密密钥池；作业仅记录不可逆凭据身份，不保存Key。更换当前Key不影响老批次查询；删除原Key会使旧批次无法访问，需恢复原Key。不会尝试别的账户来重新生成。

## 保存位置与隐私

- 作业数据库、草稿与人物参考图快照：宿主管理的 `PluginData/image_remix/`，随当前私有／加密存储，不写死盘符。
- 成品：用户指定目录下独立的 `图片翻版_时间_ID/` 子目录。每张PNG附同名JSON，记录提示词、模型、批次及用量（如果API返回）。不会覆盖输入图片；输出文件同名但内容不同时保留原文件并报错。
- 人物参考图会上传OpenAI，上传前有确认。参考图规范化到不超过2048边长；上传文件设置7天到期。云端批次输出需及时收取，官方输出文件有保留期限。
- 关闭窗口保存草稿；删除本地结束记录不删除生成图片及参考快照。活动批次不允许直接丢记录，避免失去已付费任务的恢复依据。

依据：[Batch API](https://developers.openai.com/api/docs/guides/batch)、[JSON图片编辑](https://developers.openai.com/api/reference/resources/images/methods/edit)、[文件上传与到期策略](https://developers.openai.com/api/reference/resources/files/methods/create)。

本轮验证仅使用隔离临时数据及模拟API响应，禁止真实网络请求；未调用用户Key生成收费图片，不把离线测试等同于真实账户验收。
