# AI Agent 助手

目前提供“口播”项目分页。入口为主界面快捷卡片、插件菜单“AI Agent 助手”，或任务右键“添加到 AI Agent 口播任务”。提交任务给外部 Agent 制作，并后台收取其填写的 Drive 成品；不代替 Agent 领取或启动生成。

## 自动收取成品（0.3.0）

- 插件随主程序启动，每60秒检查一次；已有作业记录同样有效，不要求重新导入或提交。关闭助手窗口不停止收取。表格与账号设置可关闭自动收取；右键“立即检查并收取成品”“重试所选任务下载”“打开原任务成品目录”提供手动入口，主程序后台任务中也可安全取消。
- 按提交时保存的表格／分页、作业ID、任务编号核对，不依据当前选中行、当前打开项目或行号猜测。复制粘贴到表格的本地作业也可按稳定ID识别。重复ID、编号不符、原目录不可用时单独提示，不下载其他任务作为替代。
- 执行状态为“已完成／完成／制作完成／生成完成／completed／complete／done”且成品栏有完整 Drive HTTPS 链接后收取。支持多条链接、文件夹及最多5层子文件夹，跳过文件夹内非视频文件；单任务最多500个视频、遍历最多1000项。文件夹无视频、缺少权限或链接尚未填好时不会误报完成。
- 保存到提交快照的原任务目录下 `result`；文件名包含作业身份和文件身份，远端名称只作为经过安全处理的文件名。不会写入共享表中的路径，也不下载到当前项目代替原目录；不会覆盖已有不同内容的文件。Drive同ID视频内容更新且校验值变化时保留旧版，另存新文件。
- 每轮最多收取8个文件，单文件10分钟上限、网络请求30秒超时，支持协作取消。失败按60秒起指数退避、最长1小时自动重试，累计次数和原因显示在说明列；单条失败不停止其他任务。手动重试只解除失败项的等待时间，不重新生成或重复提交。
- 下载先写临时文件，核对长度、Drive提供的MD5（若有）以及FFprobe视频轨道和时长，再发布成品并保存SHA-256记录。重启后根据持久记录和本地文件大小避免重复下载；本地成品丢失则重新收取。校验失败不标记已下载，正常异常和取消会清理本轮临时文件。
- 全部已知成品到位后，重新按作业ID定位云端行并核对任务编号、完成状态和成品链接，仅以RAW更新“归档状态”为“已下载”。不插入行、不修改样式／验证／正文／领取状态；下载期间链接变化或归档下拉不允许该值时，显示“已下载·待回写”，保留文件，下次只重试回写。不自动修复云端格式或扩大表格权限。
- 收取历史和文件清单位于同一私有SQLite队列中，与原作业提交记录分开，旧数据不重置。跨进程采用有心跳和超时的收取租约，避免两个软件实例同时处理同一队列；崩溃后可恢复，不永久占锁。

### 成品下载账号

插件单独注册“AI Agent · 成品下载”Drive用途，由主程序加密账号管理器管理，下载代码仅使用读取、列文件和下载操作。为兼容主程序现有Drive账号，声明宿主现有的Drive权限，不影响其他插件的绑定。

首次使用时，若本插件已选择的表格账号本来就具有Drive权限，则仅在本插件内将它用于成品下载，无需重新登录。已经明确选择／停用的成品下载绑定不会被覆盖，不借用网盘上传、审核或其他插件账号。没有Drive授权时仍可下载公开共享的单文件；文件夹和受限文件需在Google账号管理器中给本用途分配有读取权限的账号。不会读取Chrome Cookie或修改共享权限。

## 外文按约10秒分段（0.1.1）

API填表和复制表格均复用“智能文案分段助手”提供的 `script_segmenter.split` 节点，固定选择“仅10秒”，按节点默认语速、标点和短尾合并规则估算，不生成音频、不运行逐词对齐，也不额外调用AI。需启用该分段插件。

每项任务仍占一行，外文单元格写为“【第1段｜约10秒】正文”“【第2段｜约10秒】正文”等分段。段号和秒数标签只用于分组，不作为朗读内容。中文台词保持完整原样，不按外文段数猜测翻译对应关系。

预览区保留可校对的原文；实际提交和复制在后台分段，按同一适配函数输出。原任务、私有队列原文和作业ID不改变，重复准备不会叠加段号。节点的超时等提醒写到备注，与台词正文分开。约10秒不是严格10秒；短尾合并或特别长的单元可能略超，沿用节点提醒，不截字或改写原文。

已提交的旧记录不自动覆盖。要让已有云端任务使用新格式，请明确导入新版本，或按业务需要人工处理原表。分段节点不可用／正文完整性校验失败时会报错，不偷偷提交整篇原文。无可朗读内容的单条任务不会阻塞其他正常任务。

## 使用

1. 主界面加载任务，选择要交给 Agent 的任务。右键添加，或在助手点击“导入任务”；下拉菜单可导入当前列表所有口播任务，每次最多1000条。新导入且资料完整的草稿自动选中，无需逐条勾选。
2. 首次展开“表格与账号设置”，粘贴共享表格链接，填写口播分页名称（默认“口播表格”）。输入完离开文本框后保存；提交时也会保存。已有目标时默认收起设置，地址仍在私有存储，不内置个人业务链接。
3. 在预览中核对语言、口播原文、中文台词和素材。双击这些字段可以编辑待提交内容，不改主任务表。
4. 整行选择任务，Ctrl+A 全选、Shift 连选、Ctrl 多选，然后点击“提交所选（数量）”。右键提供复制表格（也可 Ctrl+C）、核对提交结果、只选可提交／待核对任务、移除草稿等操作；右键点在已选批次内不会取消多选。刷新按作业ID保留选择，不按行号串任务。
5. 提交按钮只处理所选行中资料完整的草稿，已提交／待核对／资料不全的条目不会重发。新版本移至“导入任务”的下拉菜单，需明确确认后才另建，不再使用容易遗忘的常开复选框。

中文优先来自原任务表中明确的“中文台词／中文文案／中文正文／中文／中文口播／口播中文台词”列。没有专门中文列时，完整任务名称仅作为待确认草稿。选中后点击提交或复制，会一次确认这批现有中文是否为完整台词；默认取消，不自动批准、不要求重新导入。不正确时双击中文台词修改。设置中的来源开关仅影响后续导入。不会拿被截断、被文件名规则替换的名称充当完整正文，也不自动编造翻译。

选中数量与可直接提交、待确认中文、需处理数量分别显示。即使所选资料不全，提交按钮也能点击查看具体原因，不再显示灰色“0”让用户猜测。已提交和待核对记录仍不会重发。

素材栏允许混合制作说明与 Drive 链接：提交／复制准备时提取链接到素材列，原参考栏完整追加到制作要求，不丢失说明。纯说明也移入制作要求。包含本地路径、裸文件名或非 Drive 网站链接时仍要求修正，不偷偷上传本地文件，不改原任务表。整理和中文确认仅更新现有草稿快照，保留作业ID；确认过程中任务被其他进程修改或已提交时，整批准备回滚，不覆盖新数据。

## Google 授权

“Google 账号…”打开主程序统一管理界面，与“程序设置 → Google 账号”共用加密账号库，但各插件／用途独立绑定。选择有表格编辑权限的账号，分配给“AI Agent 助手 · 口播表”，不会改变任务交付的网盘上传、审核表、任务提交表或表格监视账号。原来的网盘／表格授权会以来源标签自动显示在列表，保留原文件和旧功能的独立授权；没有取得 Google 已验证身份的旧记录不会伪造邮箱。插件不读取浏览器 Cookie，不自行保存客户端密钥或 Token，不弹出另一套授权流程。

新账号库由主程序整体 DPAPI 加密，密盘模式继续走已验证的宿主存储。浏览器能打开表格不代表桌面程序已有 API 授权。尚未配好授权时，本地导入、预览、校对和右键“复制所选任务表格”仍可使用。复制内容带表头和稳定作业ID，手动粘贴不会自动标记本地已提交；后续 API 提交会先按ID核对。

如果报 `SERVICE_DISABLED`，表示客户端所属的 Google Cloud 项目没有启用 Google Sheets API，不等于表格未共享。请在该项目启用 API，等待生效后重试；不先删除凭据或重新登录，程序不会代替用户自动修改 Cloud 项目。

## 表头与提交保护

- 按列名匹配，不写死列号。表头须在前10行，前52列内，包含作业ID、所属任务编号、任务名称、口播语言、口播台词（原文）、中文台词、执行状态。常见等价列名受支持。重复／缺失表头会拒绝写入，不偷偷使用另一个分页。
- 新任务执行状态为“待领取”，优先级为“普通”，归档状态为“未下载”。读取相应下拉验证，直接列表不兼容时先提示；第一版遇到范围型状态下拉会要求调整，不猜测合法值。
- 使用 RAW 方式在现有数据后追加数值，优先填入已有格式的空白行，不再插入继承表头样式的新行；保留空白模板的格式、下拉框和列宽，台词不会解释为公式。只填任务发起方负责的字段，未知列及执行Agent、成品、租约等后续字段以 API null 跳过，不清空模板默认值或公式。模板容量耗尽时 Google 仍可能扩展网格，超出原模板的区域需延续其格式。不会把本地任务目录上传到共享表；素材字段仅接受 Google Drive／Docs HTTPS 链接。不会替用户上传本地素材或改共享权限。
- 同一来源任务重复导入复用作业ID。已提交任务内容变更不能静默覆盖云端，需要明确新版本。项目目录不同的同编号任务不会混为一条。
- 私有队列记录目标任务目录与正文快照，提交时不重新读取主界面当前选择。数据在宿主 `PluginData/ai_agent_assistant` 命名空间内，数据库连接按操作关闭。
- 网络写入只尝试一次。先持久化“请求结果待核对”，再发请求。断线、超时、响应不完整或进程中断后保留记录，用“核对提交结果”只读查找作业ID；确认存在后恢复已提交状态。未找到不自动重发，避免迟到请求造成重复任务。
- 资料不全或待核对的单条任务不会阻塞其他正常任务。表头、账号等全局环境错误会明确结束本次操作，不无限等待。取消有协作和网络超时边界，关闭助手窗口不会中断已提交给后台的操作。

不提供强制解除结果不明记录或自动重发按钮；确需重做可明确导入新版本。请先核对云端，避免重复安排 Agent。已提交／待核对记录不能当草稿删除，云端行不会被本地删除操作删除。

Google API 参考：[追加单元格](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/append)、[RAW 输入模式](https://developers.google.com/workspace/sheets/api/guides/values)。
