# AI Agent 助手

第一版仅提供“口播”项目分页。入口为主界面快捷卡片、插件菜单“AI Agent 助手”，或任务右键“添加到 AI Agent 口播任务”。不自动启动生成、不轮询领取，也不下载成品。

## 使用

1. 主界面加载任务，选择要交给 Agent 的任务。右键添加，或在助手中点击“导入主界面所选任务”。也可导入当前列表所有包含口播台词的任务，每次最多1000条。
2. 首次粘贴共享表格链接，填写口播分页名称（默认“口播表格”），保存后记住。地址属于私有设置，不内置个人业务链接。
3. 在预览中核对语言、口播原文、中文台词和素材。双击这些字段可以编辑待提交内容，不改主任务表。
4. 勾选任务，点击“一键填入表格”。有同一作业ID的行会跳过，不覆盖 Agent 的执行状态、成品链接或其他列。只有明确再制作一版时，才勾选“作为新版本”后重新导入。

中文优先来自原任务表中明确的“中文台词／中文文案／中文正文／中文／中文口播／口播中文台词”列。没有专门中文列时，完整任务名称仅作为待核对草稿，不自动勾选提交。可双击中文台词校对保存，或确认本项目的完整任务名称确实就是完整中文台词后，勾选相应来源选项重新导入。不会拿被截断、被文件名规则替换的名称充当完整正文，也不自动编造翻译。

## Google 授权

“Google 账号…”打开主程序统一管理界面，与“程序设置 → Google 账号”共用账号库。选择有表格编辑权限的账号并分配 Google 表格功能。插件不读取浏览器 Cookie，不自行保存客户端密钥或 Token，不弹出另一套授权流程。

新账号库由主程序整体 DPAPI 加密，密盘模式继续走已验证的宿主存储。浏览器能打开表格不代表桌面程序已有 API 授权。尚未配好授权时，本地导入、预览、校对和“复制勾选任务表格”仍可使用。复制内容带表头和稳定作业ID，手动粘贴不会自动标记本地已提交；后续 API 提交会先按ID核对。

## 表头与提交保护

- 按列名匹配，不写死列号。表头须在前10行，前52列内，包含作业ID、所属任务编号、任务名称、口播语言、口播台词（原文）、中文台词、执行状态。常见等价列名受支持。重复／缺失表头会拒绝写入，不偷偷使用另一个分页。
- 新任务执行状态为“待领取”，优先级为“普通”，归档状态为“未下载”。读取相应下拉验证，直接列表不兼容时先提示；第一版遇到范围型状态下拉会要求调整，不猜测合法值。
- 使用 RAW 方式追加新行，台词不会解释为公式。不会把本地任务目录上传到共享表；素材字段仅接受 Google Drive／Docs HTTPS 链接。不会替用户上传本地素材或改共享权限。
- 同一来源任务重复导入复用作业ID。已提交任务内容变更不能静默覆盖云端，需要明确新版本。项目目录不同的同编号任务不会混为一条。
- 私有队列记录目标任务目录与正文快照，提交时不重新读取主界面当前选择。数据在宿主 `PluginData/ai_agent_assistant` 命名空间内，数据库连接按操作关闭。
- 网络写入只尝试一次。先持久化“请求结果待核对”，再发请求。断线、超时、响应不完整或进程中断后保留记录，用“核对提交结果”只读查找作业ID；确认存在后恢复已提交状态。未找到不自动重发，避免迟到请求造成重复任务。
- 资料不全或待核对的单条任务不会阻塞其他正常任务。表头、账号等全局环境错误会明确结束本次操作，不无限等待。取消有协作和网络超时边界，关闭助手窗口不会中断已提交给后台的操作。

第一版不提供强制解除结果不明记录或自动重发按钮；确需重做可明确导入新版本。请先核对云端，避免重复安排 Agent。已提交／待核对记录不能当草稿删除，云端行不会被本地删除操作删除。

Google API 参考：[追加单元格](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/append)、[RAW 输入模式](https://developers.google.com/workspace/sheets/api/guides/values)。
