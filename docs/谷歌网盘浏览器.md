# 谷歌网盘浏览器

入口：主程序“插件 → 谷歌网盘浏览器…”。可在插件管理中启用／禁用。

## 首次使用

需先挂载主程序已验证的 VeraCrypt 数据卷。收藏、文件名／目录快照、OAuth 客户端及令牌都由主程序保存在 `PluginData/google_drive_browser` 私有命名空间；无法验证卷时拒绝回退到明文位置。

可复用主程序已有 Google Drive 授权。没有授权时，在本插件“网盘授权”菜单中选择 Google Cloud **桌面应用 OAuth 客户端 JSON**，并执行“Google只读授权”。Google Cloud 项目须启用 Drive API；公开分享链接不等于 API 登录授权，账号仍需有文件读取／下载权限。新授权只请求 `drive.readonly`，不会覆盖或扩大主程序的上传授权。

## 完整缩略图及离线浏览

- 不调用 Google `thumbnailLink`，不使用其原生裁切缩略图。图片读取原图后生成自己的等比例缩略图，最长边960像素；列表以留白显示完整画面，单击后可放大查看。提供小／中／大图切换。
- 视频由独立 FFmpeg 进程解码完整帧，通过只在本机监听的限额字节范围桥接读取原视频。Google令牌不进入命令行或本地缓存，支持读取文件尾部索引。
- 每个视频缩略图最多读取32MB、解码等待40秒；服务端不按字节范围响应、格式不支持、缺少索引、超时或流量超限会显示未生成及原因，**不自动退回完整视频下载，不用裁切缩略图代替**。很小的视频可能恰好读取全部，但不要求全片先下载完。网络超时清理可能额外等待当前请求结束（单次读取超时10秒）。
- 原图自动缩略图读取上限64MB，解码像素上限6400万。大于上限不自动读取，避免异常文件耗尽资源。
- 首次打开目录会后台准备当前已加载页的缩略图；“准备离线缩略图”可补齐。“加载更多”读取后续页，不递归抓整库。可按名称查找、修改日期或大小排序，并筛选图片／视频。
- 默认“离线优先”：已经缓存的目录直接本地打开，**不登录、不请求 API**；点击“联网刷新”才更新。未访问过的目录、未成功生成或被容量淘汰的图片不能凭空离线显示。
- 收藏文件夹和单文件链接均可。收藏重复文件ID时更新现有记录，支持右键打开、重命名、移除；这些操作只修改本地收藏，不改云端星标／文件。

## 完整预览与原件

单击看完整缩略图；双击／“完整预览（缓存原件）”用于更高分辨率图片或视频播放。**完整视频播放是另一项显式操作，会提示下载原件的大小并要求确认**；只看缩略图不需要下载原件。完整预览成功后可离线再次打开、播放／暂停及拖动进度，或另存到外部素材目录。另存不覆盖已有文件，不写入密盘。GIF静态预览首帧。

## 存储、清理和限制

默认卷外缓存：`%LOCALAPPDATA%/AssistantTool/DrivePreviewCache`，也可在“预览缓存”菜单选择卷外位置。

默认上限：缩略图256MB、完整原件2GB；可调整。以最近使用淘汰旧缓存，正在播放／写入的文件被保护。缓存仅保存哈希命名的图像或媒体字节，不保存原名称、分享链接、资源密钥或Google凭据；文件名、链接、目录快照仍在密盘。缓存是明文媒体，其他有本机文件权限的人可以查看这些预览内容，这是有意的存储分离。

“清理本插件预览缓存”只清理本插件目录中受管理的文件，不删除收藏、原素材或网盘文件。改变缓存目录不会擅自迁移／删除旧缓存。这里**不改动现有智能搜索缩略图缓存和索引**。

联网、取帧和大文件处理提交主程序后台，可取消，可关闭浏览面板继续执行。程序退出依照现有后台任务退出流程，不依赖窗口持有工作线程。离线模式拒绝新联网操作，仍可查看已缓存目录／媒体。

## 验证范围

测试使用模拟Google响应、临时VC存储替身及本地合成视频；未调用真实账号、上传私有数据或消耗用户网盘流量。实际账户的权限、配额、网络速度及个别媒体格式仍需首次实际使用确认。128MB虚拟MP4（索引在尾部）通过真实FFmpeg生成完整帧，读取约1MB，验证未顺序下载全片。

API依据：[Google字节范围下载](https://developers.google.com/workspace/drive/api/guides/manage-downloads)、[目录分页与排序](https://developers.google.com/workspace/drive/api/reference/rest/v3/files/list)、[分享资源密钥](https://developers.google.com/workspace/drive/api/guides/resource-keys)。
