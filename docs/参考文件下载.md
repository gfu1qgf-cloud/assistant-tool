# 主界面参考文件下载

加载任务后，主程序按任务中的参考链接下载素材；这与AI Agent助手检查“已完成”和下载成品是两条独立流程。参考素材成功不代表Agent视频已经制作完成，不会因此显示新成品标记。

## 访问顺序

1. 命中本地索引则直接使用，不请求Google。
2. 未命中时先匿名下载公开的Google Drive文件，不读取账号库、不弹出登录。
3. 只有Google返回登录页或401／403访问拦截，才按需调用主程序凭据管理器，逐个尝试已保存且具有Drive读取权限的凭据，包括已经分配给插件的账号。账号不是独占资源；这个过程不改变任何插件的绑定，也不新增一套OAuth登录流程。
4. 当前文件成功后立即停止尝试其他凭据；本批后续文件优先尝试刚成功的凭据，仅影响本批内存顺序。相同OAuth凭据的旧副本去重，不重复请求。缺少Drive读取权限的凭据无法下载，不要求后台追加授权。
5. 每个凭据对同一文件的权限失败只尝试一次；全部无权时明确提示该文件需要核对链接／共享权限，继续其他任务，不再每隔1秒反复刷登录页。临时网络错误仍按原有有限重试处理，不因一次网络故障轮试所有账号。

## 保存与保护

通过统一账号管理器使用的凭据仍保存在原加密账号库；续期由管理器按账号版本保存。旧凭据复用管理器已有的兼容导入机制，只登记加密副本、不修改原文件、不复活已经移除的账号，不创建新的明文副本。不会读取Chrome Cookie，不会修改共享权限，不会自动打开登录网页。

授权下载沿用原任务参考目录与索引，支持原有文件／Google文档导出格式；校验文件长度和Drive提供的MD5，先写临时文件再发布。同名不同内容另存，不覆盖原素材。下载有超时、大小上限和取消检查，失败不把网页或残缺文件写进成功索引。

“需要登录”不等于“文件已删除”。若所有现有账号都失败，需要文件所有者把真实文件共享给其中一个账号，或允许知道链接的人访问。后台不能绕过文件权限。文件夹参考链接仍需提供具体文件链接。
