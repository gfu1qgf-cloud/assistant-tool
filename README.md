# 辅助小工具

一个面向 Windows 的本地桌面效率工具。它提供任务表读取、字幕与语音处理、浏览器顺序启动、表格链接监视、库存提醒，以及可选的结果整理和云端写回功能。

源码开发入口：[开发者手册](docs/developer/README.md)（插件注册、主界面与设置页、节点、后台任务、存储和发布，附可执行示例及截图）。开发文档只随源码提供，不包含在 EXE 发行包中。

## 隐私与配置

仓库和发布包不包含任何真实 API Key、OAuth 凭据、Token、表格链接、客户数据或历史运行记录。首次启动没有配置时，会打开[首次使用向导](docs/首次使用向导.md)，可创建普通配置或直接在已挂载的 VeraCrypt 卷内创建配置，之后通过程序设置填写账号与本机参数。已有配置或密盘绑定不会被空配置覆盖。

Google 服务需要用户自行创建 OAuth 桌面客户端，并把相应凭据文件放在程序目录中。程序生成的 `config.json`、Token、监视状态、库存状态和提交日志均已被 Git 忽略。

可选的 AI 视频检测目标、说明、规则和结果复核关键词全部由本机配置提供，源码不包含具体业务判定规则。

## VeraCrypt 加密数据模式

先在 VeraCrypt 中手动挂载卷，再运行根目录 `启动VC加密模式.cmd`。
启动界面只接受驱动确认的可写卷，目前验证了 Windows VeraCrypt 1.26.7。
首次迁移复制配置、凭据、插件记录、索引、附件和日志到卷内 `AssistantToolData`，
逐项 SHA-256 校验，SQLite 使用包含 WAL 的一致性备份；不删除原文件或旧备份。
公共模型、任务表格、原始素材和视频成品保持原位置，不触发重新下载模型或重建索引。

迁移启用后，正常启动也必须选择已挂载的原数据卷。启动绑定仅记录非敏感身份标识，
不保存密码；相同卷可换盘符，另一卷、普通磁盘、损坏标记或缺失主配置不能冒充原数据。
卷中途不可用时停止相关读写和后台提交，不另存程序目录或系统临时目录。
请在软件完全退出后再卸载卷，**不要强制卸载使用中的卷**。软件只关闭自身资源，
不会代你卸载手动挂载的卷；异常终止也不等于卷已锁定。

旧明文副本仍保留用于恢复，加密迁移不会抹除旧文件、SSD 历史痕迹、系统交换文件或内存转储。
同进程插件遵守主程序存储接口，这不是恶意插件沙箱；外部浏览器和 Codex 客户端自身的活动
配置仍由外部程序管理。详细范围与恢复步骤见 `docs/VC加密与书签说明.md`。

## 统一浏览器书签库

插件菜单 → **浏览器书签库…**，或 Chrome 浏览器面板 → **统一书签库**。
支持当前 Windows 用户的 Chrome / Edge 多配置、账号书签、Firefox，以及手动添加便携版目录。
导入完整网址并去重，保留原标题、文件夹及浏览器来源；不上传，也不导入密码、Cookie 或浏览历史。

清理源书签是单独的确认步骤：需要 VC 加密模式、全部浏览器关闭、源文件未变化，
先保存并校验卷内恢复副本才清理。开启书签同步时，删除可能影响其他设备或被云端重新恢复。
未知格式只导入、不清理；恢复时拒绝覆盖清理后新增的数据。浏览器自带的历史备份不自动删除。

## 运行环境

- Windows 10/11
- Python 3.10（从源码运行时）
- Google Chrome（仅浏览器启动功能需要）
- 可选的外部视频编码器及预设（仅启用视频压缩时需要）
- 首次使用字幕识别时需要联网下载所选 Whisper 模型

从源码运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 离线安全模式

程序设置 → **网络与安全** → 勾选“下次启动使用离线安全模式”，保存并重启。
也可通过工具菜单进入该设置。标题栏和菜单栏显示当前离线状态。
源码可运行 `启动离线模式.cmd`，发布版可用 `AssistantTool.exe --offline`，
参数仅影响本次运行，不修改原有配置。取消设置后重启恢复在线；不会中途切换。

离线模式在 SDK、插件和模型导入前安装联网拦截：Python TCP/UDP、DNS、
常用 Qt 客户端接口、云端 API、外部浏览器启动和显式网络子进程参数。
审核/表格监视、素材网盘同步及垃圾官网更新暂停，不清空配置、密钥或业务记录。
已缓存模型、本地素材/任务/剪辑、垃圾日历和提醒仍可使用；缺少模型时不会下载。
本地管道 IPC 和标准库内部 socketpair 保留，不能通过 localhost HTTP 代理联网。

这是**应用级离线策略，不是恶意代码沙箱或系统防火墙**。任意原生 DLL、
外部程序、原生媒体解析器内的网络路径和已经运行的浏览器可能绕过 Python Hook。
需要对不可信插件/文件保证网络隔离时，仍需操作系统防火墙或隔离环境。
拦截日志不记录 URL、请求内容或密钥；开启离线不会把 Key 标记成失效。

## 发布包

正式发布由 GitHub Actions 在 Windows runner 上使用 PyInstaller 构建。Release 中的 ZIP 由 `github-actions[bot]` 上传，并带有 GitHub Artifact Attestation。

下载后解压整个目录，运行 `AssistantTool.exe` 并完成首次使用向导。保留 `config.example.json` 作为初始化模板；不要只移动 EXE，旁边的 `_internal` 目录是运行所需依赖。

时间线播放器使用固定版本的官方 mpv Windows 运行库。发布构建会从官方
GitHub Release 下载并校验 SHA-256；校验失败或文件缺失时会直接终止打包，
不会生成缺少播放器的发布包。

验证发布包来源：

```powershell
gh attestation verify AssistantTool-Windows.zip --repo gfu1qgf-cloud/assistant-tool
```

如果从其他仓库下载，请将上面的仓库替换为实际下载来源。
构建证明必须属于下载来源仓库，不能跨仓库复制证明。

发布包根目录的 `BUILD_INFO.json` 记录版本标签、源码提交和实际依赖版本。
核对其中的 `source_commit` 与 Release 标签指向的提交，可确认源码和安装包对应。
v2.0.0 使用通过隔离媒体读取及模型兼容测试的 OpenCV 4.14 / NumPy 2.2；
不会改动系统 Python 或其他软件环境。原生第三方库不属于 pip 漏洞扫描的完整覆盖范围，
不能据此宣称零漏洞；基础 Python 迁移仍单独安排。

## 安全检查与发布

GitHub 在提交和 Pull Request 上运行 CodeQL（security-extended）；每周继续扫描。
Dependabot 跟踪依赖与 Actions 更新，仓库启用密钥扫描与推送保护。
创建新的 `v*` 标签会自动运行完整隔离测试、构建、发布包隐私检查、生成构建证明和发布。
发布完成后再运行一次 CodeQL，确保扫描结果晚于新 Release 的发布时间。
不手工上传发布附件，不公开本机配置、Token、日志或模型缓存。

当前 PyTorch 2.10 配套版本仍有已记录的条件性公告。程序不直接使用公告涉及的
`.pt2` 加载与 `torch.jit.script`；保留已验证版本，不自动跳过测试或升级不兼容依赖。
请只加载可信模型、插件和 Fusion 预设。扫描通过不代表不存在安全风险。
